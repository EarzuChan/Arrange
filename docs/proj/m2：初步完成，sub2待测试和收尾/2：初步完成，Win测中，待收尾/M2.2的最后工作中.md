## 本轮整改

2026-10-12 主人执行 pnpm verify:platform：框架 Node 221 通过；CLI 358 项中 345 通过、4 失败、9 项仅 Mac 不适用；流程在 CLI 阶段停止，未执行本次原生 CTest。

四项失败已定位为测试缺陷：三项直接匹配带 ANSI 颜色的文本；一项把 console.log 输出的彩色 PID 和任意输出分块直接转数字，得到 NaN，尚未走到后代清理断言。

2026-10-13 整改：

- PID 夹具直接输出十进制机器数据，测试从完整 stdout 读取、严格校验后验证后代已退出；该清理场景拆为独立用例
- CONFIG 文本断言统一去掉 ANSI；任务编排保留结果、失败和取消检查，删除重复的符号与精确空格要求；绘屏与颜色仍由 UI 测试验证
- CLI 自有英文测试标题、帮助、向导标签与夹具说明改为中文；注释遵守中文 // 规范；技术标识、命令、系统工具原文与格式测试数据保留
- 本篇重写为当前状态，主人“日后谈”原文完整保留；相关链接和支持范围同步修正
