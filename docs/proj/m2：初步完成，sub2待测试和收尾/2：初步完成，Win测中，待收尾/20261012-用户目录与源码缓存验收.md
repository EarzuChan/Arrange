2026-10-12，Windows/MSVC 本机验收。长期目录、缓存与恢复契约见 [Arrange 用户目录与源码缓存](../../../arch/35-Arrange用户目录与源码缓存.md)。

## 实现与范围

- CLI 统一使用 `~/.arrange`，`ARRANGE_HOME` 可显式覆盖；native 构建树在用户级目录按工程隔离，工程 `.arrange` 继续保存工程日志等工作状态。
- Arrange、JUCE、QuickJS-NG 源码缓存独立于构建树，跨进程锁、失效锁恢复、取消清理、原子发布与 commit 校验均有自动化覆盖。
- CMake/CLI 只读取同一份必需的依赖清单，缺失或没有固定 commit 时明确失败；用户显式源码覆盖与托管开关保持有效。
- 已更新本机全局 `@arrange/cli@1.0.0`，指向本工作区构建；未发布 npm 包，未删除旧构建目录。
