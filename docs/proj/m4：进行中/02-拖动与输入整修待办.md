# M4 附加：拖动原语与输入系统整修

状态：施工中。

决策见 [ADR 017](../../adr/017-拖动原语与输入系统整修.md)；长期设定见[事件与输入](../../arch/17-事件与输入.md)与[拖动与数值控件](../../arch/37-拖动与数值控件.md)。本文只记录施工和验收状态。

## 指针

- [x] 统一指针会话所有者：按下、文本拖选、拖动共用捕获（拖动开始即取消文本拖选）
- [x] 只有主键参与点击与拖动；`M.onContextClick`
- [x] 平台坐标统一浮点
- [x] 统一取消来源（失焦、隐藏、退休、受体替换、热更新、关闭）
- [x] 原生悬停跟踪，`hoverable` 的 onEnter / onExit
- [x] `M.pointerIcon` 与光标管理
- [x] `clickable` 的 `onDoubleClick`

## 键盘与焦点

- [x] 只在命中焦点受体时取键盘焦点，点击空白清除焦点并交还键盘
- [x] `KeyEvent` 与 `M.onKeyEvent` 冒泡，未消费再走默认行为，最后交还宿主
- [x] key up、重复标记、修饰键变化
- [x] Enter / Space 抬起激活，重复不连发
- [x] 诊断快捷键只在 Debug

## 拖动

- [x] 原生拖动会话：阈值、点击共存、独占、按帧累加与修饰键分段、停止 / 取消
- [x] 指针锁定（隐藏光标、无界移动、结束复位）
- [x] `createDraggableState` / `createDraggable2DState`、`M.draggable` / `M.draggable2D`

## 滚轮、状态与语义
