# 2. M2：工程模式与 Arrange Vue 正规化

目标：M2 分为上半阕与下半阕。上半阕建立 Arrange CLI 与标准工程模式；下半阕建立 Arrange Vue、phase-aware reactivity、Reactive Slot Runtime 与 Unified FramePlan。两者同属 M2，不拆成两个独立里程碑。

## M2 上半阕：Arrange CLI 与工程模式

目标：建立 Arrange CLI 的长期地位，让用户通过唯一 `arrange` 命令创建、收编、开发、构建和打包标准 Arrange 工程。CLI 是工程编排器，不替代包管理器、CMake、Vite 或 JUCE。

范围：

- `@arrange/cli`：唯一官方 CLI 包。
- `arrange.project.yaml`：工程共享配置。
- `arrange.local.yaml`：本机工具链配置。
- 标准工程形态固定为 `arrange.project.yaml`、`arrange.local.yaml`、`ui/`、`native/`、`artifacts/`。
- `arrange create` 生成标准工程。
- `arrange adopt` 收编已有 native / UI 工程。
- `arrange sync` 同步工程文件与工具链预状态。
- `arrange dev` 调起开发版。
- `arrange build` 调用 UI 与 native 构建，并默认执行 package phase。
- `arrange package` 整理已有构建产物到 `artifacts/`。
- CMake managed region 与 `package.json` 语义维护策略。
- 只有此套CLI，严禁再在`@arrange/framework`等处另维护其它CLI

验收：

- CLI 能作为用户创建项目，开发项目，编译和打包项目的几乎唯一选择。
- CLI 能管理 DEMO。


## M2 下半阕：Arrange Vue 与 Reactive Slot Runtime

目标：建立 Arrange Vue 的长期运行时地基，让 `Ref`、template、scheduler、typed slot 与 native FramePlan 有机统一。状态变化必须按实际参与阶段进入 Composition / Layout / Draw / Event / Resource 失效域。M2 以当前 Arrange host target 为边界做完整闭环；被 Lazy、Canvas、Interop 等后续专题天然阻塞的部分，随对应专题接入同一规则。不得把当前 host target 内的 compiler、hit-test、callback lifecycle、slot dirty 与 FramePlan 留成半截。

范围：

- 引入 `@arrange/vue-*` 包族或等价源码组织，接管 compiler / runtime / reactivity 的 Arrange host target 改造。
- `@arrange/framework` re-export `ref`、`reactive`、`computed`、`watch`、`watchEffect`、lifecycle 与 `nextTick`。
- Arrange compiler host target lowering：host components、typed prop、Modifier、event slot、resource slot、reactive slot。
- Arrange Vue compiler 正式接入 Arrange 工具链与 runtime 主链路；SFC、template、`<script setup>`、HMR、host component lowering 与 host target diagnostics 核心健全。
- Phase-aware reactivity：区分 composition dependency、layout slot dependency、draw slot dependency、transform slot dependency、hit-test slot dependency、event slot dependency、resource dependency。
- Reactive Slot Runtime：建立 slot binding、SlotUpdateBatch、dirty role、dirty reason 与 binding retirement。
- 当前 host components / Modifier 能力下的 hit-test 完整闭环；未来新增 Lazy / Canvas 等节点必须按同一规则接入。
- TransformSlot / HitTestSlot / EventSlot / LayoutSlot / DrawSlot dirty role 完整闭环。
- event slot / native callback handle 生命周期完整闭环：create、replace、retire、node remove、subtree delete、component unmount、HMR reload、manual reload、error recovery、source switch、QuickJS context reset。
- JS Value Phase：推进 animated refs、transition、computed UI value 与 dirty slot batch。
- VBlankSource-only 生产帧源：VBlankReady 是 visible runtime ready 的必要条件；生产环境无 animation timer fallback、visual frame timer fallback 或 synthetic production frame source。
- ManualVBlankSource 测试注入：不是 timer，不自动 tick，只在 native harness 显式 `advanceFrame(timestamp)` 时向生产 FrameScheduler / FramePlan 路径注入一帧。
- Unified FramePlan：消费 MutationTransaction 与 SlotUpdateBatch。
- 动画 API 正规化：`animatedNumberAsRef`、`animatedDpAsRef`、`animatedColorAsRef`、`animatedOffsetAsRef`、`animatedSizeAsRef`、`animatedRectAsRef`、`animatedNumberArrayAsRef`、transition 基础。
- 动画 spec 最小集：tween、spring、snap、easing 基础。
- 高层动画首批：`animateContentSize`、`Crossfade`、`AnimatedVisibility`。
- SlotUpdateBatch / dirty reason / phase counter 的非 UI 诊断模型。
- M2 性能验收计数器：component render count、VNode diff / patch count、JS Value Phase time、SlotUpdateBatch size、dirty role count、layout / paint triggered count。
- 源码组织与上游 Vue 3.5.34 fork / specialization 管理规范。

测试建立：

- Arrange Vue compiler lowering 测试。
- Arrange Vue compiler / Vite / runtime 主链路测试。
- Phase-aware dependency 测试。
- SlotUpdateBatch contract test。
- animated ref ManualVBlankSource 测试。
- NoPeer / VBlankReady lifecycle 测试。
- pending work 等待 VBlankReady 后 first frame 消费测试。
- paint slot 不触发布局测试。
- layout slot 触发必要 layout dirty 测试。
- transform / hit-test / event slot dirty role 测试。
- 当前组件和 Modifier 能力下的 hit-test 完整性测试。
- event slot / callback handle create、replace、retire、unmount、reload、QuickJS reset 生命周期测试。
- HMR / reload 后 slot binding retirement 测试。
- QuickJS native typed slot update reader 测试。
- M2 性能验收计数器测试。
- 生产路径无 timer fallback 静态 / 行为测试。

测试验收：

- `animatedColorAsRef` tick 不触发 component render / VNode diff。
- background / color / alpha 等 draw slot 只进入 draw / paint dirty。
- width / padding / fontSize 等 layout slot 进入必要 layout dirty。
- 当前 host target 下 hit-test 与视觉位置、clip、zIndex、event interest 保持一致。
- event slot / callback handle 在替换、删除、reload、HMR、QuickJS reset 后无泄漏、无旧回调触发。
- Arrange Vue compiler 是 Vite 与 runtime 的主链路，不是旁路实验。
- 同一 VBlank frame 内 MutationTransaction 与 SlotUpdateBatch 由 FramePlan 统一消费。
- 生产动画 / JS Value Phase 不由 timer fallback 推进。
- `@arrange/framework` 是用户导入 Arrange Vue authoring API 的主入口。

功能验收：

- 用户继续用 SFC、template 与 Ref authoring。
- 动画值可由 JS 计算，但高频变化不穿越普通 composition 链路。
- Debug 动画卡顿与 sawtooth 波动有可观测改善。
- dirty reason 可追踪到 slot、field、phase 与 source。
