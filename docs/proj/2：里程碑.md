# 1. 基础 UI 闭环

目标：基础完整，而不是最小 demo。`Arrange UI Pipeline` 能支撑真实 Vue/SFC UI 在 JUCE Editor 中原生显示、热更新与报错恢复。

范围：

- `@arrange/runtime` 包形态与类型提示。
- C++ `ArrangeEditor` / `config.app.useLive(...)` / `config.app.useDist(...)`。
- QuickJS 初始化、加载、执行、错误捕获。
- Vue renderer 基础。
- LayoutTree 与 native transaction 基础 batch。
- 基础节点：`Box`、`Row`、`Column`、`Spacer`、`Text`、`Input` 基础、`Image`、`Icon`。
- 基础布局链路：constraints、measure、place、draw、dirty、repaint。
- 基础 Modifier：尺寸、约束、padding、background、border、clip、shadow、alpha、offset、align、weight、`m.then`、`m.if`。
- 基础交互：clickable、hoverable、focusable、InteractionState、FocusRequester、键盘基础操作。
- 基础文本：测量、baseline、fontSize、color、weight、align、overflow、maxLines。
- 基础 Input：`v-model`、placeholder、cursor、selection 基础、change / blur / submit。
- 基础滚动：verticalScroll、horizontalScroll、ScrollState。
- 基础动画：animateFloatAsState、animateDpAsState、animateColorAsState、animateContentSize、简单 transition。
- Vite dev server 连接、真 HMR。
- `ui/` 基础发布加载。
- 错误屏与重试。

测试建立：

- 建立 TS 测试包：`renderArrange`、`ArrangeTestRule`、native harness、matchers。
- 建立 `m.testTag`。
- 建立布局 snapshot：bounds、measure、baseline。
- 建立 DrawOps snapshot。
- 建立基础 NativeTransaction contract test。
- 建立 Vue renderer native harness recorder。
- 建立 QuickJS app loading 集成测试。
- 建立 HMR / 错误屏 smoke。
- 建立 Demo 骨架：Standalone + VST3 effect、plugin/、ui-src/。
- 建立 `smoke-basic-editor`，复用 Demo scene，产出 layout / drawops / screenshot artifact。

测试验收：

- Box / Row / Column / Spacer / Text 有基础布局测试。
- 基础 Modifier 有顺序测试和 DrawOps 测试。
- Vue renderer 能测 create / update / remove / unmount。
- NativeTransaction 能驱动基础 batch。
- HMR 能自动验证文本更新、错误屏、恢复。
- Release `ui/app.js` 加载有自动 smoke。

功能验收：

- 能写一个真实插件 Editor UI。
- 改 Vue/SFC 后能热更新。
- 报错后进入错误屏，修复后可恢复。
- Release 可加载 `ui/app.js`。
- 类型提示可用。
- 基础交互、文本、布局不是摆设。

细节要求：

- reload / 错误重试 / HMR reload / F5 统一走 `live -> dist -> error` 链路。
- Debug 下 live / dist 状态在 Editor 内可见，Standalone 额外显示标题状态。
- badge、标题、错误屏、日志与必要 diagnostics toast 遵循 [开发期诊断表层](../arch/25-开发期诊断表层.md)，为未来 DevTools 留出结构化模型。
- 错误页恢复、reload、resize、source 切换不得残影或叠画。
- Standalone 支持 window / editor config 控制 resize。
- 滚动视口内 wheel 不得报错，ScrollState mirror 与 native layout/repaint 必须闭环。
- Input 文本、光标、选区与 IME bounds 必须共用真实文本布局模型。
- 动画必须按 [NativeFrameClock与动画刷新链路](../adr/003-NativeFrameClock与动画刷新链路.md) 走 native FrameClock / QuickJS RAF pump / repaint 链路。
- 新增 runtime / tooling 源码按 [具体开发的额外约束](5：具体开发的额外约束.md) 执行。
