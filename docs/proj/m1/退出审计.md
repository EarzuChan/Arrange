# M1 退出审计

更新时间：2026-05-09

## 退出原则

M1 退出必须证明 `Arrange UI Pipeline` 可用：

```txt
Vue SFC -> Arrange Runtime -> Bridge -> native RenderTree -> Layout / Paint / Input / Scroll -> JUCE Surface
```

Standalone 与 VST3、Debug 与 Release 不得存在主链路差异。

## 当前待判定项

- `animate` 跳变问题已按 ADR 003 完成底层修复：native FrameClock / QuickJS RAF pump / repaint 链路已接通，并已有 QuickJS 动画回归覆盖中间色与最终色。
- 诊断表层组件化与 overlay 锚点需最终修复。
- 首屏 Modifier / layout / paint 需人工确认无回归。
- Text soft wrap 修复后需人工复测。
- Input 长文本与 IME 需最终回归确认。
- 需要重跑退出前自动化命令并保留人工证据。

## 不得退出的回归

- Standalone 或 VST3 Release 不能启动。
- 宿主打开 editor 崩溃。
- 滚动报错或 UI 不可用。
- 错误恢复后残影 / 叠画。
- Debug 无 live 时不能 fallback dist。
- 首屏 Modifier / layout / paint 丢失，且必须手动 toggle 后才恢复。
- `animate` 只会跳变，没有补间。
- 动画使用 Promise / microtask 伪造 frame，或一次 QuickJS callback drain 完全部动画帧。
- RAF tick 后不能产出 Bridge 增量、native dirty、DrawOps 中间值或 repaint。
- Input 无法提交中文文本。
- Text 测量换行但绘制不换行。
- 自动化验证失败且无法解释。
