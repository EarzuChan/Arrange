# 正规化描述

第五期正规化已完成从“跨进程桥协议”到“同进程内核直调”的架构跃迁。Arrange 彻底抛弃了序列化、二进制协议及 JSON Bridge 等过往错误实践，确立了 **QuickJS 组合层直接驱动 Native UI 内核** 的生产模型。

1.  **彻底肃清 Bridge 体系**：删除了所有 Bridge 协议文件（`bridge.ts`、`Bridge.cpp` 等）、二进制编码、字符串前缀编码及序列化规则。生产链路不再产生“协议对象”，转而由 TS Runtime 直接调用注入的 Native API 构造 Transaction。
2.  **Typed Mutation 驱动**：Core 层（`arrange_core`）现仅消费强类型的 `MutationTransaction` 与 `TreeMutation`。所有属性（Prop）与 Modifier 均由 QuickJS 直接从 JSValue 读取并转为 Native Typed Struct，彻底告别了 JSON 解析与字符串 Payload。
3.  **事件系统原生化**：删除了 Event Slot 的字符串 Token。事件 ID 现为结构化 `EventSlotId`；参数传递不再通过 JSON 拼接，而是由 C++ 直接构造原生 JS 对象并通过 `JS_Call` 触发，确保了同进程调用的性能与安全。
4.  **内部失效逻辑归位**：删除了伪装成普通属性的 `__arrangeNativeInput...` Magic Prop，内部失效现通过明确的 `NativeInvalidationMutation` 或 Internal Dirty API 表达。
5.  **测试集精简化**：彻底删除了 TS Headless Layout 的“第二套实现”，将所有验证压力压实在真实 Native 链路上。通过 clean build 验证了核心层与宿主层已完成对 Bridge 逻辑的物理剔除。

# 简要工作日志

1.  **协议大拆除**：删除了 TS `bridge.ts`、`headlessLayout.ts`、`fixture` 以及 C++ `Bridge.cpp`/`Bridge.h`；将 `MutationTransaction` 重构为基于 `std::variant` 的 Typed Mutation 集合。
2.  **Native API 直调化**：重写了 `app.ts` 与 `renderer.ts`，由生成协议对象改为直调 `native.createNode`、`native.setModifier` 等事务 API；QuickJS 宿主改为直接读取 JSValue 字段。
3.  **属性与 Modifier 类型化**：实现了 `PropValue` 的 Native 强类型化；废弃了 `modifierPayload` 字符串字段，由 `SetModifierMutation` 携带编译好的 Native Spec。
4.  **事件调度重构**：将 `ScriptEventBridge` 重命名为 `ScriptEventDispatcher` 以去除 Bridge 误导；实现了 `EventSlotId` 的强类型化与 Hash 比较，彻底清除了 Event Slot 字符串 Token。
5.  **内部失效清理**：在 `LayoutTree.cpp` 中移除了对 Magic Prop 的解析，失效逻辑回归 `NativeInvalidationMutation`；清理了 `PublishedFrame` 在 Pipeline 中的持久化边界。
6.  **全量回归验证**：完成了 `pnpm typecheck`、`test:runtime`、`test:quickjs` 以及 `ARRANGE_CLEAN_NATIVE_SMOKE=1 test:native` 的全量通过；Demo 在 Debug/Release 模式下的 Standalone 与 VST3 均通过了 Runtime Smoke 验证。
7.  **审计与补刀**：确认生产源码中已无任何 Bridge、JSON Parse、Encoded Prop 或 Headless Layout 第二实现残留；人工验收确认 GUI 样式及交互正常。
