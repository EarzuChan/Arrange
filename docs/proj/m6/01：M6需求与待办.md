# M6 需求与待办

目标：同一套 UI 在 Live、目录 Dist 和 ZIP Dist 中保持资源语义一致。决策见 [ADR 023](../../adr/023-只读UI发布包与资源挂载.md)，长期契约见 [UI App 发布包](../../arch/14-工具链与App发布包.md)。

## 正项

- [x] 确立发布包、资源挂载、版本切换与用户数据边界，更新 ADR、里程碑及母文档。
- [x] Vite 产出版本化清单；区分入口、ESM chunk、导入资产和 `public/` 资产，构建时拒绝冲突与非法路径。
- [x] Dist 只通过目录或 ZIP 挂载读取模块与资源。无旧包回退；检查协议、条目、大小和摘要，诊断标明阶段与来源。
- [x] Live 与 Dist 共用资源消费方式；图片、SVG、字体与异步文本/字节读取按当前来源获取，退休后不回调旧上下文。
- [x] CLI 核验构建产物，按配置打包，在暂存事务中整体替换，保留签名与回退保证。
- [x] 自动覆盖 Vite、目录/ZIP、真实 QuickJS 模块、资源读取、损坏输入、CLI 拒绝错配和 Live/HMR 回归。
- [x] 完成[字节码比较](02：字节码测量与退出验收.md#字节码测量)；0.11.0 保留 ESM 源码，不加入字节码发布选项。
- [ ] Framework 0.11.x、CLI 1.3.x 与新兼容码，完成必要本地发包与 tag；不推送、不公开发布。
