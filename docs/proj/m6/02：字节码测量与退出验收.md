## Demo 交接

Framework `0.12.1` 和 CLI `1.4.2` 已发布到本机 registry（`http://localhost:4873`），tag 为 `local`。源码本地 tag 为 `v0.12.1` 与 `cli-v1.4.2`。兼容码为 `3`。Demo 使用 [本机配置覆写](../../arch/31-ArrangeCLI与工程模式.md#配置分工)。

1. `arrange sync` 后运行 `arrange dev`。打开关于页核对静态数据，编辑 `public/gallery.json` 检查重载。
2. 默认 Release 构建产出 ZIP 与字节码。在 Standalone 与 DAW 中检查图片、字体和静态数据。
3. 使用 `ui.packageFormat: directory` 和 `arrange pack` 切换载体。切换 `ui.scriptFormat` 后重新构建 UI 再打包。替换前关闭占用产品的宿主。
4. 用交付副本验收缺包、损坏和错配的错误屏。macOS 检查签名并回填平台、架构、宿主和结果。
