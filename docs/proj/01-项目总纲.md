Arrange 是面向 JUCE 的声明式原生 UI 框架：用 Vue/Vite 获得现代开发体验，用 Compose 风格布局与 Modifier 驱动 JUCE 原生绘制。

# 做

- 让音频开发者像写 Vue App 与 Compose 布局一样写 JUCE Editor UI。
- 以 `ArrangeEditor` 作为 C++ 主入口。
- 使用 QuickJS 承载 UI 逻辑。
- 使用 Vite HMR 支持开发期真热更新。
- 使用 Compose Foundation 风格的布局、样式、交互语义。

# 不做

- 不是 WebView / 浏览器套壳。
- 完全不使用 DOM、CSS、HTML 布局模型，而是以 Compose 模式为基本。
- 不让音频线程接触 JS 运行时。
- 不追求 100% 复制 Compose，只对齐核心布局与样式心智。
- 不让桥接层吞掉所有职责。

# 成功标准

- 用户能用 Vue/Vite 项目开发真实 JUCE 插件 Editor UI。
- 保存文件后 UI 能通过 Vite HMR 快速更新。
- 架构边界清晰，可维护，可扩展。

# 额外要求

- 工作态度：兢兢业业，认真磨，不追求工作得快、应付式“Patch”和“代码一下子写了好多”，只追求稳：代码干净、可维护、符合最佳实践，以免产生“克苏鲁肉块”
- C/C++ 采用 Google 码风
- TS/JS/Vue中的脚本 不需要行末分号
- 代码缩进均为 4，不需要“刻意”断行（如`var a = \n xxxx`，`class A : \n B(/**/)`），尽可能保持一行写下
- 尽可能不要“魔法值”、硬编码字符串
- 文档和注释的要求：使用中文为主（严禁使用纯英文），言简意赅，不讲大厂黑话
