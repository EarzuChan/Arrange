Arrange 是给 JUCE 的声明式原生 UI 框架。

# Hello World

App.vue

```vue

<template>
    <Column :modifier="m.fillMaxSize().padding(dp(16))" :vertical-arrangement="Arrangement.spacedBy(dp(8))">
        <Text text="Hello World" :text-style="{ fontSize: sp(50)}"/>
        <Text :text="`Clicks: ${clicks}`" :text-style="{ fontSize: sp(16), color: Color(0xFF000000) }" :modifier="m.size(dp(160), dp(36)).background(Color(0xFFFFFFFF)).clickable(handleClick)" />
    </Column>
</template>
<script setup lang="ts">
import { Arrangement, Color, dp, m, ref, sp } from "@arrange/framework"

const clicks = ref(0)
function handleClick() {
  clicks.value += 1;
}
</script>
```

InitApp.ts
```ts
import { createApp } from "@arrange/framework"
import App from "./App.vue"

createApp(App).mount()
```

YourPlugin.cpp
```c++
juce::AudioProcessorEditor* YourPlugin::createEditor() {
    arrange::juce::EditorConfig config;
    config.app.useDist();
    config.width = 520;
    config.height = 380;
    config.window.title = "Your Plugin";
    config.window.resizable = true;
    config.window.useCornerResizer = true;
    config.window.minWidth = 420;
    config.window.minHeight = 300;
#if !defined(NDEBUG)
    config.app.useLive(); // 自动探测本地开发服务器。DEBUG模式下优先加载Live，无则Fallback到Dist，再没有就报错
#endif
    return new arrange::juce::ArrangeEditor(*this, std::move(config));
}
```

# 核心特性

- 现代开发体验：引入 Vite 与 Arrange Vue（复用“Vue”的SFC 单文件组件、反应式系统、模板语法，但内部已深度改造），支持热更新：用户 UI 的改动能立即在 DAW 或 Standalone 中看到 UI 变化，无需用户重新编译C++。
- 拥抱 Compose 的声明式范式（非 DOM/CSS 体系）：以 Arrange host target、Modifier 链和严格的“布局-绘制”流程构建 UI，基本对齐 Compose 范式。
- 非套壳，纯原生轻量渲染：Arrange 使用轻量级 JS 引擎承载 Arrange Vue authoring / runtime，具体“处理”直接在 C++原生 进行。不仅产物极小，更保证了媲美纯 C++ 的高性能。
- APVTS 完美响应式处理：专为音频开发打造。在 TypeScript 侧可以直接以响应式的方式读写、监听、控件绑定 APVTS。
- 极度安全，严格解耦：UI 运行时（JS 引擎）与音频处理（Audio Thread）严格隔离，互不干涉，确保音频处理的安全与实时性。
- 多平台与灵活分发：一套代码即可编译 macOS、Windows；支持 Standalone 及 VST3 格式（其它格式将在未来持续评估和添加）。用户能在开发期使用 Live 热更，发布期则有轻量的 Dist 资源；dist 的打包位置与 live 无关。
- 组件：核心包仅提供基础内建组件（Row、Box、Text、Image、Icon等，以及Lazy家族），用户可套用任何设计系统（没有相关限制，内建组件保持高可定义性，原厂零样式或最低样式！），音频控件也完全可由用户手搓。
