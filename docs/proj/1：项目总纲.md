Arrange 是给 JUCE 的声明式原生 UI 框架。

# Hello World

界面文件和独立入口脚本分别如下，编译边界见 [SFA 与模板写法](../arch/33-SFA与模板写法.md#sfa-与纯-typescript-的编译边界)。

`App.sfa`
```sfa
<template>
    <Column :modifier="M.fillMaxSize().padding(16.dp)" :vertical-arrangement="Arrangement.spacedBy(8.dp)">
        <Text text="Hello World" :style="{ fontSize: 50.sp }"/>

        <Text :text="`Clicks: ${clicks}`" :style="{ fontSize: 16.sp, color: Color(0xFF000000) }" :modifier="M.size(160.dp, 36.dp).background(Color(0xFFFFFFFF)).clickable(handleClick)"/>
    </Column>
</template>
<script>
import { ref } from '@arrange/framework'
import { Column, Text } from '@arrange/framework/foundation'
import { Arrangement, Color, M } from '@arrange/framework/ui'

const clicks = ref(0)
function handleClick() {
    clicks.value += 1
}
</script>
```

`InitApp.ts`
```ts
import { createApp } from "@arrange/framework"
import App from "./App.sfa"

createApp(App).mount()
```

`YourPlugin.cpp`
```c++
juce::AudioProcessorEditor* YourPlugin::createEditor() {
    arrange::juce::EditorConfig config;
    config.app.useDist();
    config.width = 520;
    config.height = 380;
    config.window.title = "Your Plugin";
    config.window.resizable = true;
    config.window.useCornerResizer = true;
    config.window.minWidth = 420;
    config.window.minHeight = 300;
#if !defined(NDEBUG)
    config.app.useLive(); // 自动探测本地开发服务器。DEBUG模式下优先加载Live，无则Fallback到Dist，再没有就报错
#endif
    return new arrange::juce::ArrangeEditor(*this, std::move(config));
}
```

# 核心特性

- SFA 与响应式 authoring：借鉴 Vue 的模板与响应式算法，使用 Arrange 自己的参数、内容和重排契约，支持 Vite 热更新。见 [SFA 与模板写法](../arch/33-SFA与模板写法.md)、[热更新](../arch/06-热更新.md)。
- Compose 风格的原生 UI：Arrangable 组合、Layout、Modifier 与测量/放置/绘制共同组织界面。见 [运行时](../arch/04-运行时.md)、[布局](../arch/09-布局.md)。
- QuickJS 承载前端逻辑，C++ 与 JUCE 执行布局、绘制和输入。性能通过真实流水线的阶段工作量与耗时验证。见 [架构总览](../arch/01-架构总览.md)、[测试策略](../arch/22-测试策略.md)。
- UI Owner 与音频线程分离；音频参数及 APVTS 的声明式互操作属于后续里程碑。见 [调度线程与帧阶段](../arch/26-调度线程与帧阶段.md)、[互操作](../arch/16-互操作.md)。
- Demo 提供 Standalone 与 VST3 Effect，开发期使用 Live，发布期使用 Dist。平台和发布边界见 [跨平台开发策略](../arch/24-跨平台开发策略.md)、[工具链与 App 发布包](../arch/14-工具链与App发布包.md)。
- Foundation 提供无装饰样式的基础 Arrangable，设计系统和高级集合布局另行扩展。当前能力见 [内建 Arrangable](../arch/12-内建Arrangable.md)、[基础 API 形态](../arch/21-基础API形态.md)。
