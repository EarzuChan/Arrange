# M2 验收与防回流清单

本文定义 M2 的完成标准和防回流要求。任何任务只要没有满足本清单，不得标记为完成。

# 总体验收

M2 完成后必须证明：

- Arrange Vue 是生产主链路。
- `@arrange/runtime` 是用户 authoring API 主入口。
- Phase-aware reactivity 与 Reactive Slot Runtime 真实工作。
- Composition mutation 与 UI slot update 分离。
- Unified FramePlan 统一消费所有生产输入。
- VBlankSource 是唯一生产视觉帧源。
- 动画过程值不默认触发 component render。
- hit-test、dirty、event slot、slot binding、PublishedFrame 语义稳定。

# 功能验收

## Arrange Vue

- SFC 编译走 Arrange Vue compiler。
- template lowering 到 Arrange host target。
- `<script setup>` 可用。
- `v-if` 产生结构 mutation，并退休旧 binding。
- `v-for` key 行为明确。
- `v-model` lowering 到受控 prop + event slot。
- 用户组件最终展开为 Arrange host component tree。
- HMR reload 后旧 callback 不触发。

## Reactive Slot Runtime

- draw slot 更新只触发 draw / paint dirty。
- layout slot 更新触发必要 layout dirty。
- transform slot 更新影响 transform / hit-test。
- event slot 替换不触发无理由 layout / paint。
- resource slot 更新进入 resource / draw dirty。
- binding 在 unmount、HMR、reload、QuickJS reset 时退休。

## FramePlan / native

- MutationTransaction 与 SlotUpdateBatch 在同一 FramePlan 中消费。
- SceneFramePipeline 阶段执行记录可查。
- full repaint / full layout 有明确 fallback reason。
- JUCE `paint()` 不执行状态迁移。
- hit-test 与 zIndex、clip、scroll viewport、transform、event interest 一致。

## 动画

- `animatedColorAsRef` tick 不触发 component render / VNode diff。
- `animatedDpAsRef` 绑定 layout 字段时进入 layout dirty。
- Transition 多 child value 同帧批量推进。
- `animateContentSize` 不默认 full layout。
- `Crossfade` alpha 过程值进入 draw slot。
- `AnimatedVisibility` 退出过程无交互幽灵节点。

# 防回流禁止项

以下任一项出现在生产路径，即视为 M2 防线失败：

- 外部标准 Vue runtime 继续作为 Arrange UI 主链路。
- DOM renderer、DOM patchProp、CSS style patch 进入 Arrange 生产语义。
- JSON / string / binary buffer / command buffer 作为 JS 到 C++ 的生产提交路径。
- BridgeOp / BridgeBatch / EncodedAnyValue / EncodedProp 继续作为生产路径。
- Modifier 依赖 `modifierDebugJson`。
- Modifier 依赖 `__arrangeModifier.N.*` 展开字段。
- scroll 依赖 `__arrangeVerticalScrollValue` 或 `__arrangeHorizontalScrollValue`。
- event slot 使用 fake callback 或 `JS_UNDEFINED` 注册 active slot。
- native 根据 node id / kind 临时生成 fake valid slot。
- native internal invalidation 伪装成普通 prop。
- animation timer fallback。
- visual frame timer fallback。
- Promise / microtask / JS timer 伪造 production frame。
- JUCE `paint()` 执行 JS、layout、mutation apply、DrawOps build、dirty clear 或 request repaint。
- 测试维护 TS layout 第二实现。
- 测试维护 serialization encode/decode 第二协议。
- 测试用 fixture 保护旧 command buffer。

# 完成声明格式

任一 M2 子任务完成时，完成说明必须包含：

- 修改的生产模块。
- 删除的旧路径或旧债。
- 新增或更新的测试。
- 证明没有回流禁止项的检查结果。
- 仍未完成但不影响本任务定义的后续事项。

不得用“基本完成”“最小可用”“暂时兼容”“先保留旧路径”作为完成声明。
