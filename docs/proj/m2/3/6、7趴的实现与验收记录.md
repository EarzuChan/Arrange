## 性能采样

环境：Windows 11 专业工作站版 10.0.26200；AMD Ryzen 9 9950X，16 核/32 线程；MSVC/Ninja；Node 24.16、pnpm 10.34.5。Debug 包含上述 QuickJS 依赖优化，不能视为全链路未优化构建。

负载：真实 Showcase SFC 的 80 个完整物化条目，原生约束 520×380；注入 240 个相隔 16 ms 的帧时间戳。按优先级每 60 帧恢复、48 帧删除、36 帧重排、24 帧换色、12 帧切换选中，其余只推进帧。采样在构建结束后顺序运行两种配置，各记录一轮，不作统计显著性或跨机器性能承诺。

| 指标 | Debug | Release |
| --- | ---: | ---: |
| CPU 单帧平均耗时 | 4.47083 ms | 0.650873 ms |
| P95 | 19.8911 ms | 5.4135 ms |
| 最大值 | 44.5549 ms | 13.1357 ms |
| C++ 普通 new 次数 | 2,596,173 | 348,208 |
| C++ 累计申请字节 | 209,274,724 | 154,742,388 |
| QuickJS 分配次数 | 535,747 | 535,746 |
| QuickJS 累计申请字节 | 34,601,242 | 34,316,394 |

两种配置工作量一致：结构执行 32 次、值表达式求值 5,300 次、实际值写入 1,229 次；measure 13 次、place 82 次、paint build 114 次、hit build 106 次；候选场景复制 12,970 个节点。这里是执行阶段次数，不是节点测量总量。采样区间活跃 JS 值绑定净变化为 −16，因为最终删除了两项；随后另有整页退出基线断言，未用该净变化代替泄漏验证。

计量边界：

- 帧耗时覆盖事件、JS、原生流水线与发布，不包含 JUCE 被动 raster、GPU 和屏幕呈现延迟
- C++ 探针仅链接验收程序，统计当前 UI 线程经过普通 `operator new/new[]` 的申请，不覆盖任意 malloc、对齐分配、系统或 GPU 分配
- QuickJS 使用运行时 allocator 计数；累计申请字节不等于保留内存，活跃字节也不等于进程 RSS
- Debug 的 P95 超过 16.67 ms，不能宣称 Debug 所有帧满足 60 Hz；Release 本轮样本小于该预算，但不能代替真实宿主体验验收
- 候选场景仍复制状态，PublishedFrame 仍展平显示/命中片段，被动 paint 仍在 clip 范围重放视口显示列表；本轮不宣称完成局部栅格重绘

原始采样：`build/m23-debug-performance.log`、`build/m23-release-performance.log`。生成位置：`cpp_tests/arrange_vue_runtime.cpp`、`cpp_tests/AllocationProbe.cpp` 和 `tests/fixtures/vue-runtime/FrameApp.vue`。

## 复现与产物

在已配置 MSVC 开发环境的终端中，使用可执行的 cmake、ctest 和 ninja：

```powershell
pnpm typecheck
pnpm test:runtime
pnpm build:packages
pnpm verify:version
node --import tsx scripts/build-demo-ui.ts
node --import tsx scripts/build-vue-runtime-fixture.ts

cmake -S . -B build/m23-final-debug -G Ninja -DCMAKE_BUILD_TYPE=Debug -DARRANGE_BUILD_TESTS=ON -DARRANGE_QUICKJS_NG_SOURCE_DIR=E:/a_dev/proj/Arrange/third_party/quickjs-ng -DJUCE_DIR=E:/a_dev/proj/Arrange/third_party/JUCE
cmake --build build/m23-final-debug --parallel 6
ctest --test-dir build/m23-final-debug --output-on-failure

cmake -S . -B build/m23-final-release -G Ninja -DCMAKE_BUILD_TYPE=Release -DARRANGE_BUILD_TESTS=ON -DARRANGE_QUICKJS_NG_SOURCE_DIR=E:/a_dev/proj/Arrange/third_party/quickjs-ng -DJUCE_DIR=E:/a_dev/proj/Arrange/third_party/JUCE
cmake --build build/m23-final-release --parallel 6
ctest --test-dir build/m23-final-release --output-on-failure

& './build/m23-final-debug/cpp_tests/arrange_vue_runtime.exe' './build/vue-runtime-fixture/app.js'
& './build/m23-final-release/cpp_tests/arrange_vue_runtime.exe' './build/vue-runtime-fixture/app.js'
```

Demo 构建使用 `ARRANGE_DEMO_BUILD_TYPE=Debug` 或 `Release` 环境变量，再运行 `node --import tsx scripts/build-demo.ts`；依赖来源通过 `JUCE_DIR`、`ARRANGE_QUICKJS_NG_SOURCE_DIR` 指向上面的 `third_party` 源码。Release 不是该脚本的位置参数。

产物：

- Debug：`build/demo-ninja-debug/ArrangeDemoPlugin_artefacts/Debug/Standalone/Arrange Demo.exe`
- Release：`build/demo-ninja-release/ArrangeDemoPlugin_artefacts/Release/Standalone/Arrange Demo.exe`
- VST3：各配置同级 `VST3/Arrange Demo.vst3`
