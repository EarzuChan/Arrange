## 实测工作量

以下计数来自本轮 [99 项 TS 测试输出](evidence/新第一趴/tests.txt)，是固定场景对照，不是全应用性能承诺。

| 场景 | 固定/分段路径 | 动态/完整表达式路径 |
| --- | --- | --- |
| keyed 列表 12 次替换：名称检查 / 位置读取 | 0 / 48 | 48 / 48 |
| 多层参数 40 次值变化：值求值 / 结构执行 | 200 / 0 | 240 / 0 |
| 20 次颜色变化：Modifier 链对象分配 | 60 | 100 |
| 同上：新链保存的元素引用数 | 180 | 280 |
| 同上：无关 width 表达式求值 / 结构执行 | 0 / 0 | 20 / 0 |

中间条件退出只增加 1 次结构执行；单条目条件退出再增加 1 次，根与列表执行次数保持 1，无关条目条件保持 1。随后的兄弟文字变化增加 0 次结构执行。链分配计数包含 FA 的必要组合；元素引用数不是字节数或原生实例数量。FFI 创建/移除/插入计数记录操作数，不把递归删除的后代数量伪装为单条操作数量。

## 拆除前的优化证据（历史）

计数来自真实编译结果和运行入口，见 [TS 测试输出](evidence/第一趴/tests.txt)。

| 对照场景 | 固定调用 | 动态对象调用 |
| --- | --- | --- |
| 40 次值变化：名称检查增量 | 80 | 120 |
| 同场景：参数位置读取增量 | 80 | 0 |
| 同场景：结构执行增量 | 0 | 0 |
| 12 次外层重排后一次值变化：值描述分配 | 48 | 60 |
| 同场景：动态参数组分配 | 0 | 12 |
| 同场景：值绑定求值 | 44 | 44 |

这证明固定路径减少名称检查与描述分配，没有减少必要值消费或改变默认工厂时机。固定名称位置在编译时生成，正式定义在调用点首次运行时连接；不宣称编译器已对任意外部模块做完整跨文件静态求值。列表词法闭包与动态 key 不进入这类缓存。

Painter 像素对照覆盖 7 种缩放 × 3 种对齐 × 2 种 tint × 2 种目标尺寸，共 84 组；逐像素比较，允许位图插值与矢量覆盖率在半像素边界产生每通道一级量化差。SVG 固有尺寸按视口处理，资源释放不破坏已发布内容。
