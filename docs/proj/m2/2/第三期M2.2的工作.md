# M2.2 第三期：CLI 重写工作区

本期重建 CLI 的工程文件托管、同步状态机和命令编排。旧 CLI 及 `cli/old-src` 仅作历史参考，不作为新版设计或完成度依据。

## 当前状态

2026-10-09：create/adopt、CONFIG/SETUP、dev/build/package 已实现，本轮 Mac 工程、构建打包及开发运行验收完成。Windows 的真实机器验收留待切换开发机；Demo 迁移和旧脚本废除后续开展。Demo 两路临时接入与 Live 资源验收也已完成，正式 `demo/` 与旧脚本保留。结果与证据集中见[本轮验收](本轮验收.md)。

| 部分 | 实现状态 |
|---|---|
| CLI 入口和命令注册 | 正式入口统一平台/TTY 闸门，命令参数与退出接通，自动化使用显式装配与交互策略 |
| Project/local YAML 与 Zod schema | 明确 `native.target`、UI 输出目录与本机 generator/architecture/Developer 环境 |
| ManagedItem、Wrapper、File/Cluster/Region | 注册与通用机制分开，各级只检查自身，Scanner 沿现有归属遍历；生成与更新共用定义 |
| CONFIG SCAN/RESOLVE/APPLY | 已接通；统一兼容检查、文件快照、注入交互、取消门控与失败恢复记录 |
| SETUP | 已实现独立扫描、工具确认、本机配置保存、UI install、Debug/Release CMake configure 与准备记录 |
| create | 已生成完整最小 UI/native 工程，先展示写入计划，支持可选立即 sync |
| adopt | 已接通新建/复制/原位引用、明确 target、共用 CONFIG 接入与可选 SETUP；失败保留记录 |
| build | 已编排真实 UI/native 构建、所选范围 clean、构建状态记录和默认 package |
| dev | 已编排 Debug Live 服务、Release/原生单范围打包运行与每次 native 增量构建，监管就绪、信号和退出 |
| package | 已定位 CMake 真实 artifact、复制完整 bundle/UI、暂存提交/回退、轻量清单和 Mac 签名检查 |
| Windows/Mac 平台适配 | 实现均已编写；Windows 的真实 Developer 环境、构建和运行尚待 Windows 开发机验证 |

Mac 已完成本轮约定范围的真实验收，回归检查和小日志已归档。Windows 当前只有平台实现与自动化替代测试，不能视为 Windows 机器验收。

## 本轮范围

先完成成熟 CLI，使工程经过 CONFIG 与真正 SETUP 后能够随时 dev/build/package。开发与验证可使用临时真实工程，不以迁移 Demo 作为本轮前置条件。

以下工作延后：

- Demo 迁移到新版工程模式，旧脚本废除与 CI 切换。
- 独立事务恢复命令；当前保留失败记录和备份供检查与继续处理。
- Developer ID 签名、notarization、installer、安装到系统目录和发布自动化。
- 全仓源码指纹或严格二进制来源证明；本轮使用准备记录、CLI 构建状态与轻量打包清单识别已知失配。
