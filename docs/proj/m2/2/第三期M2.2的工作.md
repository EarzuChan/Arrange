## 本期固定原则

- `ProjectState` 完全取代 `ProjectContext`，并包含 `rootDir`。
- File、Cluster、Region、ManagedItem 都是无状态定义。
- File → Cluster → Region 是物理关系；ManagedItem → Region 是逻辑关系，允许跨文件、跨 Cluster。
- SCAN 无副作用；RESOLVE 交互修复并在副作用后全量重扫；APPLY 只执行确定的常规更新。
- 缺失文件或结构必须先作为 SCAN 问题报告，不能在 SCAN 中直接创建。
- create、adopt、sync、build、dev、package 共用同一套托管和生成定义。
- `.arrange/` 只承载本机事务记录和未来缓存，不进入 Git，也不替代 project/local 配置。
