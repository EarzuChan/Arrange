# M2.2 第三期：CLI 重写工作区

本期重建 CLI 的工程文件托管、同步状态机和命令编排。旧 CLI 及 `cli/old-src` 仅作历史参考，不作为新版设计或完成度依据。

## 当前状态

CONFIG 已实现并接入 `sync --config`；`--scan`、UI/native 范围、交互重扫和 Apply 均有自动化验证。SETUP 尚未实现，完整 sync 会明确报告未完成。其他命令仍按下表推进。

| 部分 | 状态 |
|---|---|
| CLI 入口和命令注册 | 可运行；sync 参数已对齐母文档 |
| Clack 创建向导与 framework 版本选择 | 已有较完整实现 |
| Project/local YAML 与 Zod schema | 已统一 State、配置诊断、可选 null 与空字符串；保存创建向导的 pluginType |
| ManagedItem、Wrapper、具体 Region | 已重写；7 个托管项关联 9 个 Region，支持跨 UI/native 共同管理 |
| File/Cluster 统一生成模型 | 已实现 CMakeLists.txt、package.json、.npmrc 的统一生成与检查 |
| CONFIG SCAN/RESOLVE/APPLY | 已接通；含兼容性校验、文件快照核对和事务记录 |
| SETUP | 已定职责和独立 LSRA，具体矩阵与实现未完成 |
| create 真实工程生成 | 尚未接通统一生成链 |
| adopt、build、dev、package | 命令骨架存在，编排未完成 |

## CONFIG 验证

在仓库根执行：

```bash
npm run typecheck --workspace @arrange/cli
npm run test --workspace @arrange/cli
npm run build --workspace @arrange/cli
```

2026-09-16：类型检查、构建与 48 项测试通过。测试入口：

- [模型矩阵](../../../../cli/tests/config-model.test.ts)：Wrapper、outer/inner、文本与 JSON 判定。
- [CONFIG 集成](../../../../cli/tests/config-sync.test.ts)：扫描、交互重扫、精确更新、并发编辑及写入故障。
- [CLI 冒烟](../../../../cli/tests/config-cli.test.ts)：真实子进程、参数、退出码和本地 registry 兼容性校验。

测试工程和本地 HTTP 服务在测试结束时清理。交互分支由测试驱动验证，未进行人工终端交互验收。

创建向导另经一次性模拟验证：全选、逐项选择和取消均通过，共用托管项只询问一次；未留下临时测试文件。

已有试验工程需按[托管项定义](../../../../cli/src/managed/ManageItems.ts)更新合并项 ID，并按 [CMake 定义](../../../../cli/src/cmake/CmakeStuffs.ts)把原 FetchContent Region Wrapper 拆为地址/版本两个。旧托管项 ID 会报告 Fatal，不作自动迁移。
