# 实现

## 第一步：native 收束

改 CMake：

- 删除 `ARRANGE_BUILD_DEMO`：DEMO已事实离体（指已解除cmake项目的内部粘连关系），故这个玩意要得到肃清
- 删除外部 `ARRANGE_WITH_JUCE`
- 删除外部 `ARRANGE_WITH_QUICKJS_NG`
- root CMake 默认引入 JUCE + QuickJS-NG：开箱即用
- 保留 source override：
    - `JUCE_DIR`
    - `ARRANGE_QUICKJS_NG_SOURCE_DIR`
    - `FETCHCONTENT_SOURCE_DIR_*`
- 新增外部 facade target：

```cmake
Arrange::framework
```

内部仍保留：

```txt
arrange_core
arrange_quickjs
arrange_juce
```

但要做到用户靠引入`framework`直接能开箱即用，不需要调配任何设置。

先不搞。Helper涉及对UI工程的自动化处理，这和用户用什么包管理器等都有关系。目前不搞，你无需理会，未来会再审慎处理（先设计、写文档、再实现）！
