# M5-EX：字体与文字样式

状态：Windows 原型已验证，macOS 原型待验证。M5 的追加篇，主题是字体样式 API 与相关的文字排版修正；本文记录需求、范围、验收、原型结论与施工状态，定稿后的长期设定迁入 arch 与新 ADR。

## 目标

文字能指定字体族、字重与字形，系统字体与随 App 打包的字体都可用，Windows 与 macOS 上选中同一字面、伪造行为一致；字体环境变化后，Text、Canvas 与绘制修饰器中的文字都重新排版。

## 现状

- `TextStyle` 只有字号与行高，所有文字都用 JUCE 默认无衬线字体：Windows 为 Verdana，macOS 为 Lucida Grande（[基础类型](../../arch/10-基础类型.md)中字体族、字重、字形列为尚未实现）。
- Windows 上 JUCE 8 的窗口绘制走 Direct2D 加 DirectWrite，字形是原生渲染；离屏位图（模糊、阴影等缓存）中的文字走 JUCE 软件渲染。
- 字体环境代际（[文本输入与绘制](../../arch/18-文本输入与绘制.md)）已有，但没有任何生产代码推进它；推进后 Text 会重新测量，Canvas 与绘制修饰器中的 `drawText` 排版结果缓存在绘制片段里，不会重建。

### JUCE 8.0.12 字体行为（源码调研）

- 没有数值字重。字体由「族名 + 样式名字符串」确定；粗体、斜体只看样式名里是否有完整单词 `Bold`、`Italic` 或 `Oblique`，因此 `SemiBold` 不算粗体，`Semi Bold` 算。
- Windows 选字面：先按英文字面名在族内精确匹配（忽略大小写）；失败时交给 DirectWrite 按 700 或 400 两档加斜与不斜找最接近的字面，请求的 Medium、SemiBold 缺失时落到 400。
- macOS 选字面：先查内存加载的字体，再在族内精确匹配样式名；失败时取族内列出的第一个样式，不保证是 Regular。
- 伪造：请求的样式名不在族的样式列表中、且含 Bold 或 Italic 时，在 HarfBuzz 上合成粗体（0.04 em，不改字距）与斜体（倾斜 0.1）。Windows 原生绘制靠 DirectWrite 自己的模拟；macOS 纯色文字经 CoreText 绘制时只套用了倾斜，合成粗体不生效，渐变填充走轮廓时又生效；离屏软件渲染走 HarfBuzz 轮廓，两者都生效。
- 内存字体：`Typeface::createSystemTypefaceFor(bytes)`。Windows 上字体对象存活期间加入进程级字体集合，可按名字找到；macOS 登记在 JUCE 自己的表里。`FontOptions::withTypeface` 直接使用给定字面，不经名字匹配，也不触发 JUCE 的合成。
- 可变字体：HarfBuzz 从 DirectWrite 与 CoreText 建字体时不带调节轴取值，排版与离屏轮廓按默认实例，原生绘制按命名实例，两者错位。
- JUCE 内置的 HarfBuzz 含 `hb_style_get_value`，但 JUCE 的原生字体句柄是内部类型，公开 API 拿不到 `hb_font_t`；字面的字重与斜体需各平台原生读取（Windows 用 DirectWrite，macOS 用 CoreText）。

### 原型结论：Windows

原型为独立控制台程序（JUCE 8.0.12 + DirectWrite），同一组文字分别画到 Direct2D 原生图像与软件图像上对照。

- 字重读取：DirectWrite `IDWriteFont::GetWeight` 给出真实字重（Segoe UI 为 300/350/400/600/700/900 及各自斜体，Microsoft YaHei UI 为 290/400/700）。OS/2 表的 `usWeightClass` 对可变字体的命名实例一律是 400（Bahnschrift、Segoe UI Variable），不可用。枚举时跳过 DirectWrite 模拟出来的字面与非常规宽度的字面（如 Arial Narrow）。
- JUCE 名字匹配实测：`SemiBold` 忽略大小写命中 `Semibold`；`Semi Bold` 落到 Bold；`Medium` 落到 Regular；Arial 请求 `SemiBold` 落到 Regular；Gabriola 请求 `Bold` 得到 DirectWrite 模拟粗体；Gabriola 与 YaHei 请求 `Italic` 得到 `Oblique` 模拟；未知族名落到 Arial。印证了不能依赖名字匹配。
- 自定匹配：按 CSS 规则选字面结果确定（Segoe UI 500→Regular、800→Black；Arial 600→Bold、800 斜体→Bold Italic；YaHei UI 600→Bold，斜体回落到正体并需伪造）。经 `withTypeface` 绘制正常。
- 自带字体：字节经 `createSystemTypefaceFor` 加载、`withTypeface` 使用，中日文字自动回落到 Microsoft YaHei UI 与 Yu Gothic UI，分段与绘制正常。
- 可变字体：Bahnschrift 各命名实例的 HarfBuzz 排版宽度完全相同，软件图像全部按默认字重绘制，Direct2D 则画出各实例的真实字重，确认错位，只支持静态字面。
- 伪造：原生字形加约 0.045 em 的轮廓描边，观感接近 DirectWrite 自己的模拟粗体；16px Segoe UI 下比真 Bold 略重。错切 0.2 至 0.25 的斜体观感合理。JUCE 自带的伪斜体（YaHei 请求 `Italic`）在 Direct2D 上是倾斜的、在软件图像上是正体，两条路径不一致，确认伪造由 Arrange 自己绘制。
- 默认字体候选：Segoe UI 加 Microsoft YaHei UI（中文回落）在 15px 下清晰，均为静态字面，优于当前的 Verdana。

## 范围

### 1. 文字样式 API

- `fontFamily`：字体族名列表，按顺序回落；末尾隐含平台默认字体。
- `fontWeight`：100 至 900 的数值，规则同 CSS；另给 `FontWeight.Thin` 至 `FontWeight.Black` 常量，只是数值的写法便利，样式名不向下传递。
- `fontStyle`：`'normal'` 或 `'italic'`。
- 用于 Text 的 `style`、Input 的 `textStyle` 与 `DrawScope.drawText`；进入排版缓存键与原生 schema。

### 2. 字面解析由 Arrange 完成

- 枚举族内全部字面，经平台原生接口读出每个字面的真实字重与斜体（Windows 为 DirectWrite `GetWeight`，macOS 为 CoreText），按族缓存；系统字体与自带字体同一套。
- 按 CSS 字体匹配算法选字面：请求 400 至 500 时先找 500 以内，再往下，再往上；小于 400 先往下；大于 500 先往上；斜体依次找斜体、倾斜体、正体。
- 选中的字面经 `withTypeface` 交给 JUCE，不依赖 JUCE 的名字匹配与触发式合成，两个平台结果一致。
- 只支持静态字面；可变字体只按默认实例使用，不暴露调节轴。

### 3. 伪粗体与伪斜体

- 有真字面就用真字面，没有时才伪造，默认规则同 CSS `font-synthesis`：请求 600 及以上而选中字面低于 600 时伪造粗体；请求斜体而族内没有斜体与倾斜体时伪造斜体。
- 可关闭伪造，关闭后严格使用选中的字面。
- 伪造由 Arrange 自己绘制：斜体为绘制时的错切变换；粗体为字形轮廓加描边（约 0.045 em，小字号可再调低），字距不变。窗口、离屏两条路径效果一致。

### 4. 系统字体与自带字体

- 系统字体按族名使用。
- 自带字体经 Vite import 或 `public/` 取得地址，以 `defineFontFamily(name, faces)` 声明，faces 给出地址与可选的字重、字形覆盖；字节走现有资源获取层（live 与 dist 同一条链路），加载后由运行时持有字面。
- 加载完成前用回落字体排版，到达后推进字体环境代际重排；可声明预加载，首帧等声明的字体到齐。
- 默认字体改为各平台的静态 UI 字体（避开 Segoe UI Variable、SF Pro 等可变字体），具体字体由原型确定。
- 缺字回落继续交给平台：中日韩文字与 emoji。

### 5. 字体环境代际与文字重排

- 字体注册表变化、自带字体到达或默认字体变化时推进代际。
- 代际推进后 Text 与 Input 重新测量；Canvas 与绘制修饰器中含文字的绘制片段重建并重绘，不重新布局。

## 本期不做

- 富文本与一段文字内的多种样式。
- 字距、OpenType 特性（等宽数字等）、下划线等装饰线。
- 可变字体调节轴。

## 验收

- 同一组字体样式在 Windows 与 macOS 上选中相同字面，伪造规则一致；缺失字重不再静默落到常规体，也不随填充方式改变粗细。
- 自带字体在 live 与 dist 下都可用，加载前后文字重排正确。
- 推进字体环境代际后，Text、Input、Canvas 与绘制修饰器中的文字都按新字体重排，有原生测试覆盖。
- Demo 有一页字体样式展示：字重阶梯、斜体、伪造对照、自带字体与中英混排。
- 长期设定沉淀到 arch，决策记入新 ADR。
