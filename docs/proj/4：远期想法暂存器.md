# Arrange 专用副作用

- `useFrameEffect`：基于 native FrameClock 的逐帧副作用。
- `useArrangeIdle`：等待 Vue flush、MutationTransaction、FramePlan 与 SceneFramePipeline 稳定。
- `useNativeSubscription`：管理 native callback / subscription 生命周期。
- `useResourceEffect`：资源加载、释放与错误诊断绑定。

普通副作用仍优先使用 Vue `onMounted`、`onUnmounted`、`watch`、`watchEffect` 与 `effectScope`。专用副作用进入里程碑前必须重新设计 API、生命周期和测试口径。
