# 正规化描述

第四期正规化已圆满完成对第三期“半挂状态”与“影子链路”的彻底出清，确保了声明式输入到 Native 输出的**唯一绝对路径**。

1.  **Event Slot 真实化**：废除了 QuickJS 中通过字符串查找进行的 `JS_UNDEFINED` 假注册。现在，Event Slot 的生命周期与 JS Callback 强绑定，只有存在真实函数的 Prop 才会建立 Slot。Native 输入事件不再产生“空响”回调，彻底解决了点击与滚动报错的回归问题。
2.  **Scroll 链路回归声明式**：删除了 JUCE 直接修改 Native 状态（旧 `__arrange...` 派生 Prop）的后门。滚轮事件现在严格遵循 `WheelIntent -> Scroll Event Slot -> JS State Change -> Standard setModifier` 链路。JS 状态成为了滚动数值的唯一生产事实源。
3.  **核心数据结构去兼容化**：`PublishedFrame` 彻底剥离了引用别名，实现了“持久内容”与“瞬时变化”的物理隔离。`ArrangeNode` 转向值语义的 `CompiledModifier`，并引入了结构化 Diff（取代字符串 Canonical Diff），确保了失效标记（Dirty Attribution）的精确性。
4.  **Modifier 语义与顺序严密化**：通过 `PaintChainOp` 显式描述了 Padding、Size、Background 等 Modifier 的编译顺序，消除了绘图阶段靠字符串补丁猜顺序的弊端。同时，TS 侧完成了 `BridgeModifierPayload` 的类型化，消除了 `unknown` 带来的类型黑盒。
5.  **验收标准硬核化**：Smoke 测试不再仅仅“数数”，而是通过真实 Invoke 点击、滚动、提交等 Event Slot 并验证状态回写，确保了生产链路的真实可用。隔离了 TS 侧的布局参考实现，防止其污染生产 API 导出。

# 简要工作日志

1.  **清理假 Slot 与派生 Prop**：删除了 QuickJS 中的 `JS_UNDEFINED` 占位逻辑；删除了 JUCE 侧直接写入 `__arrangeVerticalScrollValue` 的逻辑。
2.  **类型与隔离**：定义了 `BridgeModifierPayload` 真实 Schema；将 `layout.ts` 隔离为测试专用的 `headlessLayout.ts`；收拢了 `app.ts` 中的 Vue 类型转换。
3.  **核心模型迁移**：`ArrangeNode` 的 Modifier 归于值语义；重构 `PublishedFrame` 结构并迁移所有调用方，删除旧引用兼容层。
4.  **精准 Diff 与顺序语义**：实现结构化 `diffCompiledModifier`；引入 `PaintChainOp` 链式结构，解决 Padding 与绘制区域的顺序耦合。
5.  **Smoke 测试升级**：修通了 QuickJS Smoke 的真实点击与滚动调用；新增了 Input Submit 的真实 Invoke 测试；强制要求 C++ Smoke 从编译后的节点读取 Slot 信息。
6.  **链路收口与防回归**：删除了 `BridgeBatch` 中不再使用的 `eventSlots` 旁路字段；修正了 `ScriptEventBridge` 以防止为无 Handler 的 Prop 创建“幽灵 Slot”；统一了 Event Prop 与普通 Prop 的写入链路。
7.  **完整回归验收**：通过了 `typecheck`、`test:runtime`、`test:native`、`test:quickjs` 以及 `smoke:demo`（含 Release 模式）。静态扫描确认生产源码中已无旧派生 Prop 及假注册逻辑残留。
