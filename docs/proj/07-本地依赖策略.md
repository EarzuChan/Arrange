# Native dependencies

Arrange native code must be reproducible from a clean clone.

## Toolchain

Windows first target:

- Visual Studio Build Tools / MSVC.
- CMake from Visual Studio or a normal CMake install.

This repository must not depend on CLion build directories, CMake `_deps` from another project, or `ArrangeOld`.

## Dependency entrypoint

All native third-party dependencies go through:

```cmake
include(cmake/Dependencies.cmake)
```

Current pinned dependencies:

| Dependency | Source | Pinned tag | Used by |
| --- | --- | --- | --- |
| JUCE | `https://github.com/juce-framework/JUCE.git` | `8.0.12` | Real Standalone/VST3 demo and later `arrange_juce` |
| QuickJS-NG | `https://github.com/quickjs-ng/quickjs.git` | `v0.14.0` | Future real JS engine integration |

## Clean checkout overrides

For local development, these may point to clean checkouts:

```powershell
-DJUCE_DIR=C:/dev/JUCE
-DARRANGE_QUICKJS_NG_SOURCE_DIR=C:/dev/quickjs-ng
```

CMake also supports standard `FETCHCONTENT_SOURCE_DIR_*` overrides for clean checkouts.

Rejected sources:

- `ArrangeOld`.
- Any `build/_deps/juce-src` or QuickJS cache copied from another project.
- Any path hard-coded to one developer's machine.
