# M3 整期验收

2026-10-09。本期基于 M2 发布基线 `d722bec` 在 `codex/m3` 实现高级 UI 细节。12 项能力均已实现，并通过全仓 TS、原生 Debug / Release、独立安装包消费及工件构建验收。窗口辅助验证和仍需真人补测的范围单独记录。施工记录见[任务待办](01-M3任务待办.md)。

Framework 版本为 `0.0.0-m.3.0`，内部协议为 6；版本统一取自 `arrange.version.json`。CLI 未随本期升版，Framework 与 CLI 均未发布 npm。M2 的 Windows CLI、鼠标和精密触控板实机验收仍保留为发布前拖尾。

## 最小真人手测单

- **Windows M2 发布拖尾**：按[CLI 本轮验收](../m2：已完成，某些待测试和收尾/2：已完成，待Win测/本轮验收.md)复验 create / adopt / sync / dev / build / package；检查普通滚轮与 Precision Touchpad 在同轴和交叉轴嵌套容器中的自然方向、边界、反向及惯性。手势中移动指针后应保持开始时的滚动落点；开始新手势才重新命中。
- **最终 Standalone 窗口与真实系统 IME / 剪贴板**：先在 M3 Gallery 核对输入后仍能点击页面按钮、四种 Lazy 模式的第 500 项跳转 / 动画回顶 / 编辑重排 / 删除，再测试 macOS / Windows 系统输入法。在 M3 Gallery 的多行 Input 中选择一段文字，再输入中文候选；确认预编辑、提交、取消、一次 Undo / Redo，以及复制粘贴含换行和非 BMP 字符。输入时滚动、缩放窗口并切换焦点，检查候选窗、光标、选区和临时下划线的位置；在 Lazy 的 Input 中编辑后滚出可见区再回来，确认会话连续。
- **真实 DAW**：装载本期 VST3，检查宿主键盘抢占下的 Tab / Shift+Tab、Input 文本按键、Enter / Space 点击、方向焦点与焦点滚入；调整 Editor 尺寸、切换页面并操作 Lazy 跳转及动画，确认无卡死、旧输入残留或明显视觉错位。DAW 与系统设备体验不由无 peer 自动化测试代替。

本期工件位于 `artifacts/npm/arrange-framework-0.0.0-m.3.0.tgz`、`build/m3-demo-debug/ArrangeDemoPlugin_artefacts/Debug/Standalone/Arrange Demo.app` 和 `build/m3-demo-debug/ArrangeDemoPlugin_artefacts/Debug/VST3/Arrange Demo.vst3`。原 CLI 工件已另存 `artifacts/npm/m2-baseline/arrange-cli-1.0.0.tgz`。npm 工件只承载 JS，原生消费者独立通过项目 CMake 入口链接 `Arrange::framework`。
