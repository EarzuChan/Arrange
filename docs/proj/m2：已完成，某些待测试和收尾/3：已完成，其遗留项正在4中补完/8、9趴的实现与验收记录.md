## 实际成本与计量边界

240 帧真实 Showcase 混合负载包含选择、换色、列表反转、删除和恢复；每帧重放同一正式 PublishedFrame 到 520×380 的 JUCE Image。表中来自一次独立双配置采样，不是预设性能目标：

| 指标 | Debug | Release |
| --- | ---: | ---: |
| 含原生流水线、绘制与分配探针的平均帧耗时 | 7.727 ms | 2.474 ms |
| 上述帧耗时 P95 | 23.395 ms | 8.383 ms |
| 240 次 paint 累计 | 323.060 ms | 91.169 ms |
| 单次 paint 平均 | 1.346 ms | 0.380 ms |
| glyph 提交累计 | 121.541 ms | 65.575 ms |
| 负载中的必要新增排版 | 3 | 3 |
| 上述新增排版累计 | 5.823 ms | 0.703 ms |
| 片段访问 / 整段跳过 | 39,720 / 19,560 | 39,720 / 19,560 |
| DrawOp 访问 / 跳过 | 15,840 / 0 | 15,840 / 0 |
| 实际文字提交 | 4,080 | 4,080 |

本场景主要由整段剔除减少工作，因此操作级跳过计数为零；专项另行验证操作级剔除及状态恢复。稳定重复 paint、纯颜色和滚动场景有独立“不新增排版”断言，不能把混合负载的 3 次必要排版解释为重放排版。

另一项 80 项中文/英文/emoji 原生列表专项，在初始化和内容变更合计 83 次排版中，Debug 排版累计约 6.857 秒、Release 约 0.674 秒。该数值包含准备阶段与字体 fallback 成本，说明冷内容准备仍有明显成本；不会因稳定重放变快就将其隐去。

glyph 计时是后端提交耗时；JUCE Image 计时不包含真实窗口交换链呈现、GPU 完成或输入消息排队。旧调查的约 89.5 ms 窗口 paint 与此处计量范围不同，不据此宣称固定加速倍数或输入卡顿已被实机证明解决。候选场景仍复制节点状态，命中快照仍使用既有发布模型；本轮删除的是绘制发布的强制整树展平。

## 自审记录（2026-09-18）

主人确认本轮 Windows Debug live 的性能体验明显改善。随后对文本资源、输入几何、片段复用与裁剪路径进行代码审查，并用链接当前 Debug 原生库的独立探针核验，确认三项 P2 问题：

- 自动换行的行尾/下一行行首共用字节位置，`boundsForRange` 却调用全局行查找求横坐标，选区错误落到上一行末尾。字号 18、行高 24、宽度 35 的 `a b c d e f` 全选，后两行选区宽度均变为 1。这是原核心算法遗留，本轮统一输入入口后仍未消除。
- JUCE `effectiveLineLength` 含换行 glyph 的 advance，直接用作可见行宽会扩大测量结果、偏移居中/末端对齐及行末光标。同配置下 `A` 宽约 10.1245，而 `A\nB` 第一行宽约 15.3314。
- 在提取输入几何前跳过 ligature placeholder，丢失后端分摊的 advance 和字符位置。`e` + combining acute + `X` 中，首字形实际前进约 8.8228，保存的首段宽却只有 4.4114，点击 x=3 就定位到组合字符之后；光标位置与点击阈值不一致。需分别提取绘制字形与完整簇/输入几何，不涉及承诺完整 grapheme 编辑能力。

审查时的探针源码、输出及构建记录位于 `build/m23-review-probe.cpp`、`build/m23-review-probe.log`、`build/m23-review-probe-build.log`。随后主人授权修复三项问题，现已完成：

- 选区采用当前行的横坐标，自动换行边界的光标归属下一行；保留显式换行两侧的位置区别。
- 行宽由实际笔位置和前进量取得，排除换行但保留空格；输入几何保留占位字形，并合并同一字符区间对应的多个字形范围。
- `arrange_retained_paint` 新增完整/反向/部分多行选区、软换行点击与光标、显式空行及尾随空格验证；居中/末端对齐对照独立单行绘制，组合字符点击逐点对照 JUCE 后端，组合字符与家庭 emoji 绘制逐像素对照 JUCE `GlyphArrangement`。
- 修复后的 Debug/Release 原生全套各 9/9 通过；日志为 `build/m23-review-fix-debug-build.log`、`build/m23-review-fix-release-build.log`、`build/m23-review-fix-debug-tests.log`、`build/m23-review-fix-release-tests.log`。既有缓存复用、资源寿命和两级剔除回归继续通过。
- Debug/Release Standalone 与 VST3 均已重建，日志为 `build/m23-review-fix-demo-debug.log`、`build/m23-review-fix-demo-release.log`。三项自审问题已关闭；修复后的实际窗口交互尚未另行人工验收。
