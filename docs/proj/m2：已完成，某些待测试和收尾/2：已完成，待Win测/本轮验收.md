实际验收暴露并修复以下问题：

- CMake 裸 `--parallel` 会覆盖 `CMAKE_BUILD_PARALLEL_LEVEL`。CLI 现在尊重已设置的标准环境变量，未设置时仍使用默认并行；真实 Ninja 按 `-j4` 构建。证据：[修复前对比](验收证据/demo-cli/parallel-before-fix.json)、[实际参数](验收证据/demo-cli/manual-cmake-parallel.log)。
- Live 模块已连上时，Painter 原先仍读包内文件。现在资源来源跟随实际 Live/Dist，Framework 统一异步获取、解码、发布和退休处理；完整 Debug dev 不预构建或打包 UI。先构建再打包 Debug 的中间补偿方案已撤回。长期规则见[资源处理](../../../arch/14-工具链与App发布包.md#资源处理)，原故障见[修复前 Debug 日志](验收证据/demo-cli/manual-dev-debug-before-fix.log)。
- Vite `publicDir` 资源变更原先没有 Live 重载通知，现沿标准 `full-reload`；ESM 资源沿标准模块更新。默认 UI 模板补 `vite/client` 和 `node` 类型，支持直接导入图片；Dist 包根 URL 单次解码以匹配空格、中文和百分号文件名。
- Mac HTTP 完成及 pending 请求退出时，原共享池存在平台临时对象/消息线程销毁顺序问题。现每任务独立释放 Mac 临时对象，共享池在 JUCE GUI 关闭时收回，SVG 锁响应任务取消。原生回归包含真实阻塞 HTTP 退出，未以提前结束服务或跳过析构取得通过。
