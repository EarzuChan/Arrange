# M2.4 整期验收

2026-10-08–09。第 11 节及 After M2.4 收尾完成自动化验收；10 月 9 日主人检查并试玩 Debug live Demo，确认 OK。本文记录本次实施、迁移与证据；长期契约仍以 [运行时](../../../arch/04-运行时.md)、[基础 API](../../../arch/21-基础API形态.md)、[调度](../../../arch/26-调度线程与帧阶段.md) 等母文档为准。历史分趴报告保留当时结果，不将旧报告中的失败改写成成功。

## 本次收尾

- 动画按实际帧时间处理不规则帧及跨多个循环的 delay；等目标重定向释放帧需求，完成通知校验动画代际。复用 tween 的数值缓冲，减少颜色与矩形采样的临时数组；输出对象仍按值契约创建。动画实现归入 `animation/value.ts`，公共入口不变。
- 颜色统一检查有限 uint32。SFA 消融保留动态校验、对象字段求值顺序及副作用，不把可变 const 对象或遮蔽的 `Object.freeze` 当成静态常量。错误颜色保留旧发布输入，修正后可恢复。
- 修复动画、pre/post 观察与 setup 中卸载的重入清理；frameDeadline 完成或取消立即释放所属闭包；副作用运行中停止后不重新订阅。初始化和最终清理尽量执行完所有清理，聚合异常并保留原业务错误。
- 修复动态参数改名后的失败恢复：子值任务重试先消费仍失效的父结构，按最新参数形状执行；正常纯值变化仍跳过结构。补动态改名、非法/重复名称、类型失败恢复及 `a-slot:header`/`#header` 等价的真实 SFA 回归。
- 真实 Demo Gallery 的 Input 已验证：退出首帧和中途反向保留编辑值及受体身份；完全退出后重新进入才初始化。移除已解决的 FIXME。原生 SVG 烟雾测试改为驱动真实 message-thread 完成通知，避免持有该线程阻塞等待后台 SVG 解码；测试设置超时。
- 清理无调用的编译/宿主辅助、失效 CJS 文件、类型与旧兼容字段，共用 SFA 测试求值器；保留实际生产使用的响应式算法和上游版权。来源、删留理由与覆盖率局限见 [清理证据](收尾证据/cleanup-summary.md)，生产调用拓扑及允许保留项见 [源码审计](收尾证据/source-audit.md)。修正既存 TS/C++ 格式债，未修改格式规则。
- 按主人复核删除 ref 词汇和 CSS 扩展名专用黑名单、旧事件语法解析残支，以及旧 API/旧 helper/旧出口的专门拒绝断言；正式声明参数与生命周期错误仍按当前契约验证。业务显式声明 ref 参数经真实 SFA 正常编译、调用与响应更新。
- 清除自有源码英文说明、块注释及编译标记注释；SFA 转换改用正式模块声明身份和类型化契约，编译期开关声明归入真实初始化模块。修正映射类型误登记、动画对象字段、无限过渡两端值、局部引用别名及源码列定位，并补 3 项真实编译运行回归。文档统一区分 SFA 模板/脚本的特色转换与原始 `.ts` 写法，Ref 自动解包限定于模板作用域，详见 [SFA 母文档](../../../arch/33-SFA与模板写法.md)。

两处日后谈均已处理：保留 nextTick 的语义检查点用途，Ref 写入同步、UI 失效由统一帧消费；焦点/一次性提交等待与 Compose 帧时钟的区别见 [调度母文档](../../../arch/26-调度线程与帧阶段.md)。当前没有公开 awaitFrame 或程序化焦点空壳。动画使用生产 VBlank 时间戳，手动帧源只用于同一路径的测试；PublishedFrame 不代表显示器已经呈现。

## 固定场景与工作量

TS 的固定声明/动态对象对照来自当前生产编译器及同一 Framework；记录宿主只验证结构、求值、写入与身份，不承担布局计算。当前实测为：

| 场景 | 固定/分段 | 动态/完整表达式 |
| --- | --- | --- |
| keyed 列表 12 次替换，名称检查/位置读取 | 0/48 | 48/48 |
| 多层参数 40 次值变化，值求值/结构执行 | 200/0 | 240/0 |
| 20 次颜色变化，Modifier 链分配/元素引用数 | 60/180 | 100/280 |
| 同上，无关 width 求值/结构执行 | 0/0 | 20/0 |

独立条件、条目、重复内容调用、父子传播与退休由相应用例检查作用域执行增量和身份；结构协调减少与结构完全跳过分开断言，不凭总体帧率推断。

原生基线为 **同一生产 SceneFramePipeline 的局部路径与强制完整重建对照**，不是历史版本跑分：409 个节点，每种场景各 20 次更新，完整路径清除阶段缓存并标记全树结构失效；基线准备成本不计入耗时/分配。每轮结果与完整布局、DrawOps 及命中结果核对。Release 单次采样如下，完整的阶段耗时/节点/分配字节见 [local-work-release.txt](收尾证据/local-work-release.txt)。
