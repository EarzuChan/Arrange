# 禁止或警告

## 未定义/非法标签

`div`、`span`、原生 `input`、原生 `canvas` 等未定义/非法标签直接进入可诊断错误：别使用HTML的标签，我们不认！

## class / style

元素的 `class` 与 `style` 不被处理，开发期警告。用户须使用 `modifier`。

## SFC style 块

`<style>` 块不处理，开发期警告。

## 通用 @click

通用点击交互不走 Vue `@click` 主模型，会警告。用户应使用：

```ts
m.clickable(onClick)
```

因为：洋葱模型修饰符，允许在深处才 Clickable（外层如果设了 Padding，Padding 区域不会 Clickable）
