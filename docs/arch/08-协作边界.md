# 协作原则

Arrange Ts Runtime 不直接访问 LayoutTree、DrawOpsBuilder、PublishedFrame 或 JUCE Component。JUCE 不理解 Arrange Ts Runtime 逻辑 Arrangables 层级结构。JS 与 native 通过 typed mutation、typed slot update、InputIntent 与 FramePlan 协作。

用户交互以 Modifier 和 Arrange event slot 为主模型。点击、滚动、focus、hover、pointer、text input 等能力必须进入 Arrange 的命中、输入、dirty 与 FramePlan 链路。
