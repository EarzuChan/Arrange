# 目标

为旋钮、滑杆、开关、XY Pad 等可拖动控件提供逐层叠加的能力：手势原语只给位移，数值状态负责把位移变成数值，设计系统只负责外观。参数控件与普通 UI 控件共用同一套原语。

本文是拖动手势原语与数值拖动状态的母文档。原生拖动会话（阈值、捕获、独占、取消、指针锁定与交付）见 [事件与输入](17-事件与输入.md#拖动会话)；参数 gesture 见 [互操作](16-互操作.md#参数即-ref)；公开签名见 [基础 API 形态](21-基础API形态.md)。

拖放（拖入拖出文件或内容）不属于本文。

# 分层

| 层 | 能力 | 是否持有数值 |
|---|---|---|
| 原生拖动会话 | 命中、阈值、捕获、独占、取消、指针锁定、按帧累加 | 否 |
| 手势原语 | `M.draggable`、`M.draggable2D` 及其状态 | 否 |
| 数值拖动状态 | `createValueDragState()`、`adjustable()` | 否，读写外部绑定 |
| 设计系统控件 | Knob、Slider、Switch 等外观 | 否，读取数值状态 |

每层只使用下层的公开能力。自定义控件可以从任意一层开始组合。

# 手势原语

```ts
const drag = createDraggableState((deltaDp, modifiers) => {
    offset.value += deltaDp
})

M.draggable(drag, {
    orientation: 'horizontal',
    onDragStarted: start => {},
    onDragStopped: stop => {},
})
```

- 状态在 setup 中创建一次。`onDelta` 属于状态，因为位移的消费者是状态；开始与停止回调属于 Modifier，随使用场景配置。
- `isDragging` 是状态上的响应式只读字段，可直接驱动视觉。也可通过 `interactionState` 选项接入 [InteractionState](17-事件与输入.md#interactionstate)。
- 位移单位为逻辑 dp。`draggable` 只交付所选轴的分量；`draggable2D` 交付二维位移。
- 每段位移附带该段生效的修饰键。修饰键在拖动途中变化时，原生在变化点分段交付。
- `onDragStarted` 收到按下点的本地坐标、节点尺寸与修饰键；`onDragStopped` 收到速度与是否取消。正常结束与取消都调用且只调用一次，回调执行前已交付全部剩余位移。
- 选项：`orientation`、`enabled`、`startImmediately`（跳过阈值）、`pointerLock`（隐藏光标、无界移动）、`interactionState`。
- 手势原语不处理双击、键盘与滚轮，这些由同节点上的其它原语声明。

吸附拖动 `M.anchoredDraggable`（开关、抽屉：锚点、阈值、松手后动画归位）属于后续能力，复用同一会话。

# 可编辑值

数值拖动状态不保存数值本身，而是读写一个可编辑值：

```ts
interface EditableValue {
    readonly value: number
    begin?(): void
    set(value: number): void
    end?(): void
}
```

- `value` 为响应式读取。`begin` / `end` 标出一次连续编辑，可省略。
- `editableRef(ref)` 把普通 ref 包装为可编辑值，没有 begin / end。
- 参数通过 `param.editable()` 取得可编辑值，读写归一化值，begin / set / end 对应参数 gesture，见 [互操作](16-互操作.md#参数即-ref)。

# 数值拖动状态

```ts
const knob = createValueDragState({ value: gain.editable(), mapping: 'vertical' })
```

```sfa
<Box :modifier="M.size(48.dp, 48.dp).then(adjustable(knob, { pointerLock: true }))" />
```

配置（均为状态上的响应式字段，可随时修改）：

| 字段 | 含义 | 默认 |
|---|---|---|
| `value` | 可编辑值 | 必填 |
| `range` | `{min, max}`，仅用于 `editableRef` | `{0, 1}` |
| `step` | 写入时吸附的步长，按全程比例 | 无 |
| `defaultValue` | 复位目标 | 参数默认值；ref 无默认时不可复位 |
| `fullRangeDp` | 走完全程所需的拖动距离 | 200 |
| `fine` | `{factor, modifier}` 精调倍率与修饰键 | `{0.1, 'shift'}` |
| `mapping` | `'vertical'`、`'horizontal'`、`'both'`、`'angle'` | `'vertical'` |
| `angleSweepDeg` | `angle` 拖法的有效扫角，以正上方为中心对称 | 270 |
| `wheel` | `false` 或 `{fraction}`：每 16dp 滚轮位移对应的全程比例 | `false` |
| `keyboard` | `{small, large}`：方向键与 PageUp / PageDown 的步长 | `{0.01, 0.1}` |

只读状态：`value`、`fraction`（0..1，供绘制）、`isDragging`、`isEditing`。

动作：`reset()`、`stepBy(n)`（按 `keyboard.small` 步进 n 次）、`setFraction(f)`。三者都是一次完整编辑。

## 映射

- 内部一律按全程比例计算：`fraction = (value - min) / (max - min)`。参数的可编辑值本身就是 0..1，skew 由参数自身范围处理。
- `vertical` 向上增加；`horizontal` 向右增加；`both` 取横向与纵向位移之和（向右、向上增加）。位移除以 `fullRangeDp` 得到比例变化。
- `angle` 以节点中心为圆心，按按下点到当前点的角度变化计算，跨越 ±180° 时连续展开；角度变化除以 `angleSweepDeg` 得到比例变化。它是相对拖法，按下不跳到指针所指角度。
- 精调倍率作用于其生效那段位移。

## 累加与写入

- 拖动开始时记录起始比例，之后对位移按段累加得到未量化的目标比例，再夹到 0..1。
- 写入时才按 `step` 吸附。吸附结果与当前值相同则不写。
- 首次真实写值时调用 `value.begin()`；拖动停止或取消时，若已 begin 则调用 `end()`。没有改变数值的拖动不产生编辑。
- 拖动期间外部数值变化不改写累加起点；参数在 gesture 中本就忽略宿主回传，结束后对齐。
- 离散编辑（复位、键盘步进、`setFraction`）各自是一次完整的 begin / set / end。滚轮连续滚动以 300ms 静默为界合并为一次编辑，拖动开始会提前结束它。

## `adjustable()`

`adjustable(state, options)` 返回一个 Modifier，只组合以下公开原语：

- `M.draggable` 或 `M.draggable2D`（`both` 与 `angle` 使用二维），附带 `pointerLock`、`startImmediately`。
- `M.clickable({ onDoubleClick: reset })`；不可复位时省略双击。
- `M.focusable()` 与 `M.onKeyEvent`：方向键（上 / 右增加）、PageUp / PageDown、Home / End。
- 启用 `wheel` 时加 `M.onWheel`。
- `M.semantics({ role: 'slider', valueText, increment, decrement })`；`valueText` 默认取参数文本，可由选项覆盖。

需要不同组合的控件可以不用 `adjustable()`，直接用 `knob` 和原语自行拼装。

# 设计系统控件

设计系统控件只读取 `fraction`、`isDragging` 与交互状态绘制外观，并把右键接到 `param.showHostMenu`（参数控件）或自定义菜单。核心不内置任何控件外观。

```sfa
<Knob :state="knob" :size="48.dp" :label="gain.text" />
```

# 测试

- 手势原语：在原生测试工具中模拟拖动会话，断言阈值、分段修饰键、停止回调只调一次且在剩余位移之后。
- 数值状态：断言参数端 begin / set / end 序列，包括取消必有 end、无变化无编辑、步进参数小位移不卡住、精调途中切换不跳变。
- 语义测试使用 [测试策略](22-测试策略.md#事件测试) 中的 `performPointerDrag`。
