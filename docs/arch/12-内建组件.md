# Box

叠放子节点。

```ts
interface BoxProps {
  modifier?: Modifier
  contentAlignment?: Alignment
  propagateMinConstraints?: boolean
}
```

子节点默认 `TopStart`；子节点 `m.align(...)` 优先于 `contentAlignment`。

# Row

水平线性布局。

```ts
interface RowProps {
  modifier?: Modifier
  horizontalArrangement?: HorizontalArrangement
  verticalAlignment?: VerticalAlignment
}
```

支持 `weight`、主轴 arrangement、交叉轴 alignment。

# Column

垂直线性布局。

```ts
interface ColumnProps {
  modifier?: Modifier
  verticalArrangement?: VerticalArrangement
  horizontalAlignment?: HorizontalAlignment
}
```

语义与 Row 对称。

# Spacer

只占空间，不可挂载子组件。

```ts
interface SpacerProps {
  modifier?: Modifier
}
```

# Text

文本显示节点。由 C++ 侧负责测量、intrinsic、baseline 与绘制缓存。

```ts
interface TextProps {
  modifier?: Modifier
  text: string
  textStyle?: ArrangeTextStyle
  color?: ArrangeColor
  textAlign?: TextAlign
  maxLines?: number
  minLines?: number
  softWrap?: boolean
  overflow?: "clip" | "ellipsis" | "visible"
}
```

`Text` 只做显示，不处理输入。文本布局复用 Arrange 的统一文本测量基础设施。

# Input

文本输入节点。由 Arrange 自绘文本、光标、选区和占位符，并通过 `ArrangeEditor` 对接 JUCE 文本输入能力。

```ts
interface InputProps {
  modifier?: Modifier
  modelValue?: string
  "onUpdate:modelValue"?: (value: string) => void
  state?: InputState
  placeholder?: string
  textStyle?: ArrangeTextStyle
  enabled?: boolean
  readOnly?: boolean
  singleLine?: boolean
  minLines?: number
  maxLines?: number
  inputMode?: "text" | "decimal" | "numeric" | "password"
  cursorColor?: ArrangeColor
  selectionColor?: ArrangeColor
  selectAllOnFocus?: boolean
  commitMode?: "change" | "blur" | "submit"
  onSubmit?: () => void
  inputTransformation?: InputTransformation
  outputTransformation?: OutputTransformation
}
```

`v-model` 是便捷写法；底层建议同时支持完整的 `InputState`。

# Image

位图或资源图片。

```ts
interface ImageProps {
  modifier?: Modifier
  source: ImageSource
  contentScale?: ContentScale
  alignment?: Alignment
  alpha?: number
  tint?: ArrangeColor
  contentDescription?: string
}
```

`ContentScale`：`Fit`、`Crop`、`FillBounds`、`Inside`、`None`。

# Icon

小型矢量或符号图形。

```ts
interface IconProps {
  modifier?: Modifier
  source: IconSource
  size?: Dp
  tint?: ArrangeColor
  contentDescription?: string
}
```

默认尺寸可为 `dp(24)`。

# Canvas

高性能自定义绘制节点，不是 HTML canvas。默认采用 retained display list 思路：先生成绘制命令，再由 C++/JUCE 执行。外部定位先冻结，DrawScope、缓存与失效策略后续细化。

```ts
interface CanvasProps {
  modifier?: Modifier
  onDraw: (scope: DrawScope) => void
  cacheKey?: unknown
  invalidation?: "auto" | "manual" | "frame"
  contentDescription?: string
}
```

Canvas 默认不承诺任何专门高频数据源；频谱、波形、meter 等专用通道先放后续设计。

`FlowColumn` 对称。

# LazyColumn / LazyRow

大型列表必须使用数据加 slot，不使用普通 children 全量创建。

```vue
<script setup lang="ts">
const state = rememberLazyListState()
</script>

<template>
  <LazyColumn
    :items="tracks"
    :item-key="track => track.id"
    :item-content-type="track => track.kind"
    :state="state"
    :content-padding="dp(8)"
    :vertical-arrangement="Arrangement.spacedBy(dp(4))"
  >
    <template #item="{ item, index }">
      <TrackRow :track="item" />
    </template>
  </LazyColumn>
</template>
```

```ts
interface LazyColumnProps<T> {
  modifier?: Modifier
  items: readonly T[]
  itemKey?: (item: T, index: number) => string | number
  itemContentType?: (item: T, index: number) => string | number | undefined
  state?: LazyListState
  contentPadding?: PaddingValues | Dp
  verticalArrangement?: Arrangement.Vertical
  horizontalAlignment?: Alignment.Horizontal
  reverseLayout?: boolean
  userScrollEnabled?: boolean
  beyondBoundsItemCount?: number
}
```

`LazyRow` 对称，使用 `horizontalArrangement` 与 `verticalAlignment`。

规则：

- 只物化可视范围、预取范围、焦点保持所需项目。
- `itemKey` 是状态保持边界；缺省使用 index，增删/重排时开发期警告。
- `itemContentType` 用于测量缓存与复用优化；不影响语义。
- Lazy 自身是滚动容器，不能再套同方向普通滚动。
- `beyondBoundsItemCount` 默认由运行时决定；用户只在特殊性能场景覆盖。
- item slot 不应产生全局副作用；被回收和重建是正常行为。

# Lazy State

```ts
const state = rememberLazyListState({
  initialFirstVisibleItemIndex: 0,
  initialFirstVisibleItemScrollOffset: dp(0),
})

state.scrollToItem(index, dp(0))
state.animateScrollToItem(index, dp(0))
```

状态字段：

- `firstVisibleItemIndex`
- `firstVisibleItemScrollOffset`
- `visibleItemsInfo`
- `totalItemsCount`
- `viewportStartOffset` / `viewportEndOffset`
- `isScrollInProgress`
- `canScrollBackward` / `canScrollForward`

这些字段是只读响应式镜像；滚动真实状态由 C++ 侧持有。

# LazyGrid

```ts
GridCells.Fixed(3)
GridCells.Adaptive(dp(160))
GridItemSpan(2)
GridItemSpan.MaxLineSpan
```

```ts
interface LazyVerticalGridProps<T> {
  modifier?: Modifier
  columns: GridCells
  items: readonly T[]
  itemKey?: (item: T, index: number) => string | number
  itemContentType?: (item: T, index: number) => string | number | undefined
  itemSpan?: (item: T, index: number) => GridItemSpan | number
  state?: LazyGridState
  contentPadding?: PaddingValues | Dp
  verticalArrangement?: Arrangement.Vertical
  horizontalArrangement?: Arrangement.Horizontal
  userScrollEnabled?: boolean
  beyondBoundsItemCount?: number
}
```

`LazyHorizontalGrid` 对称，使用 `rows: GridCells`。

Grid 规则：

- `Fixed(n)` 固定列/行数。
- `Adaptive(minSize)` 根据 viewport 自动计算列/行数。
- `itemSpan` 支持跨列/跨行；`MaxLineSpan` 用于整行/整列 header。
- 不承诺 masonry / 瀑布流；同一行/列按最大交叉轴尺寸对齐。
- Grid 状态与 LazyList 类似，使用 `rememberLazyGridState()`。
