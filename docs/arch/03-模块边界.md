# JS 包

## @arrange/runtime

用户主包。提供 `createApp`、内建组件、Modifier、基础类型、动画 API、interop hooks、HMR runtime client 与类型声明。

## @arrange/vite-plugin

开发与构建工具。负责默认 dev server、HMR bridge、无 HTML 的 App bundle、资源产物处理、Arrange 语义诊断。

## create-arrange

可选脚手架。用于生成标准 UI 源码项目。

# C++ 模块

## arrange_core

纯核心：scene state、layout tree / layout node、测量与布局、Modifier typed decode / compile、样式类型、dirty attribution、invalidation graph、hit test、DrawOps build。

## arrange_quickjs

JS 宿主：QuickJS runtime/context、模块加载、JS/C++ binding、event slot registry、生命周期。

## arrange_juce

JUCE 适配：

- `ArrangeEditor` 托管宿主生命周期、平台事件采样、frame clock 接入与 passive paint 转发。
- `EditorSceneHost` 承担 JUCE editor 内部 scene host / composition root 职责。历史 `EditorSurface` 命名只能作为过渡，不得继续表示业务绘制表面。
- `ArrangeRuntime` / `SceneRuntime` 统一接收 intent、event、transaction，驱动 FramePlan 与 frame phases，不负责 JUCE 绘制。
- `FramePlanner` 生成 FramePlan 并记录阶段执行 / 跳过 / fallback 原因。历史 `FrameCoordinator` 命名只能作为过渡。
- `SceneFramePipeline` / `FramePipeline` 执行 apply、measure、layout、DrawOps build、hit-test build、diagnostics build 与 publish frame，不是单纯 render helper。
- `RuntimePackageLoader` 负责 live/dist 包加载，不参与 frame planning。
- package binder、session、action、chrome、input、diagnostics 等对象只能作为 intent producer、state owner、adapter 或 view builder，不得成为第二调度中心。
- `ScriptEventBridge` 负责 native event slot 到 QuickJS callback 的调用边界。
- `JuceDrawOpsPainter` 只执行 DrawOps 到 JUCE Graphics 的平台绘制。
- `JuceTextServices` 提供平台文本测量。
- 文本输入相关对象持有 text editing state / caret / selection / IME bounds，并通过 typed invalidation 进入 FramePlan。
- `ImageResourceCache` 解析/缓存包内图片。
- `DiagnosticsScene` 负责开发期诊断视图构建并复用 core pipeline。历史 `DiagnosticsOverlay` 命名只能作为过渡。

## arrange_audio / interop

音频互操作：参数绑定、APVTS adapter、host transport、meter/event bridge。可先并入 `arrange_juce`，边界保持独立。

# 运行时

职责：承接 Vue 渲染结果，创建与更新 Arrange 界面树。

不负责：JUCE 绘制、音频参数底层实现、平台输入细节，也不绕过 FramePlan 直接执行三件套。

# QuickJS 宿主

职责：启动脚本运行时、加载模块、暴露最小绑定、管理生命周期。

不负责：布局算法、绘制细节、业务组件语义。

# 桥接协议

职责：定义脚本世界如何表达创建、更新、删除、事件回调。

不负责：把所有对象互相暴露成一团，也不让 JS object ops / JSON mirror 成为生产事实源。

# 核心布局

职责：约束、测量、放置、Modifier 链、dirty attribution、失效传播、DrawOps build 所需结构状态。

不负责：SFC 语法、热更新连接、音频处理。

# JUCE 适配

职责：`ArrangeEditor` 托管、输入 adapter、frame clock adapter、被动绘制转发；绘制、资源、诊断、输入会话按子模块聚合而非八股拆碎。

不负责：理解 Vue 逻辑组件、保存 UI 业务状态、绕过 intent / FramePlan 执行输出阶段，也不把诊断表层混入用户 App layout。

# 热更新

职责：连接开发服务器、接收更新、触发运行时重载。

不负责：核心布局算法、音频线程通信、发布资源打包策略。

# 错误屏

职责：承接加载、运行、热更新和协议错误，并提供重试。

不负责：吞掉错误或替用户修复业务逻辑。

# 项目骨架

最好按这样子来组织：

```txt
packages/
  runtime/
  vite-plugin/

native/
  arrange_core/
  arrange_quickjs/
  arrange_juce/

demo/
  plugin-src/
  ui-src/

tests/
```
