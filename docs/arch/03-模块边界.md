# JS 包

## @arrange/runtime

用户主包。提供 `createApp`、内建组件、Modifier、基础类型、动画 API、interop hooks、HMR runtime client 与类型声明。

## @arrange/vite-plugin

开发与构建工具。负责默认 dev server、HMR bridge、无 HTML 的 App bundle、资源产物处理、Arrange 语义诊断。

## create-arrange

可选脚手架。用于生成标准 UI 源码项目。

# C++ 模块

## arrange_core

纯核心：界面树、布局、Modifier、样式类型、dirty propagation、hit test。

## arrange_quickjs

JS 宿主：QuickJS runtime/context、模块加载、JS/C++ binding、callback handle、生命周期。

## arrange_juce

JUCE 适配：`ArrangeEditor` 托管宿主生命周期与 frame tick；`RuntimePackageLoader` 负责 live/dist 包加载；`ScriptEventBridge` 负责 native 事件到 QuickJS callback 的调用边界；`JuceDrawOpsPainter` 执行 DrawOps 到 JUCE 绘制；`JuceTextServices` 提供平台文本测量；`InputTextController` 负责文本输入几何、caret/selection/IME bounds 与焦点输入绘制；`ImageResourceCache` 解析/缓存包内图片；`DiagnosticsOverlay` 绘制开发期表层；输入状态由 `InputTextSession` 承载。

## arrange_audio / interop

音频互操作：参数绑定、APVTS adapter、host transport、meter/event bridge。可先并入 `arrange_juce`，边界保持独立。

# 运行时

职责：承接 Vue 渲染结果，创建与更新 Arrange 界面树。

不负责：JUCE 绘制、音频参数底层实现、平台输入细节。

# QuickJS 宿主

职责：启动脚本运行时、加载模块、暴露最小绑定、管理生命周期。

不负责：布局算法、绘制细节、业务组件语义。

# 桥接协议

职责：定义脚本世界如何表达创建、更新、删除、事件回调。

不负责：把所有对象互相暴露成一团。

# 核心布局

职责：约束、测量、放置、Modifier 链、失效传播。

不负责：SFC 语法、热更新连接、音频处理。

# JUCE 适配

职责：`ArrangeEditor` 托管、输入转发、重绘请求；绘制、资源、诊断、输入会话按子模块拆分。

不负责：理解 Vue 逻辑组件、保存 UI 业务状态，也不把诊断表层混入用户 App layout。

# 热更新

职责：连接开发服务器、接收更新、触发运行时重载。

不负责：核心布局算法、音频线程通信、发布资源打包策略。

# 错误屏

职责：承接加载、运行、热更新和协议错误，并提供重试。

不负责：吞掉错误或替用户修复业务逻辑。

# 项目骨架

最好按这样子来组织：

```txt
packages/
  runtime/
  vite-plugin/

native/
  arrange_core/
  arrange_quickjs/
  arrange_juce/

demo/
  plugin-src/
  ui-src/

tests/
```
