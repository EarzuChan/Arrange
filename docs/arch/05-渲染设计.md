# 宿主模型

JUCE 侧主入口是 `ArrangeEditor`。它托管一块 Arrange 画布，由 Arrange 内部完成布局、绘制与事件处理。

# JUCE 知道什么

- Editor / 画布尺寸。
- 绘制回调。
- 鼠标与键盘事件。
- 重绘请求。

# JUCE 不知道什么

- SFC、逻辑组件。
- 模板结构。
- 响应式状态。

# 职责

`arrange_core::PaintModel` 只把 RenderTree 收敛为平台无关 DrawOps。`arrange_juce::JuceDrawOpsPainter` 只把 DrawOps 翻译为 JUCE 绘图调用，并通过 `ImageResourceCache` 读取包内图片资源。JUCE 平台事件进入 Arrange 后，由 Arrange 完成命中测试与事件分发。

# 原则

JUCE 是舞台，不是导演。用户不需要接触内部根组件或 Surface。
