# 宿主模型

JUCE 侧主入口是 `ArrangeEditor`。它托管 Arrange scene host，由 Arrange 内部完成输入归一、状态变更、布局、绘制准备与事件处理。

# JUCE 知道什么

- Editor / 画布尺寸。
- 绘制回调。
- 鼠标与键盘事件。
- 来自 FramePlan / PublishedFrame 的被动重绘请求。

# JUCE 不知道什么

- SFA、逻辑Arrangable。
- 模板结构。
- 响应式状态。

# 职责

`arrange_core::DrawOpsBuilder` 把 layout tree / scene state 收敛为平台无关、不可变的绘制片段。`arrange_juce::JuceDrawOpsPainter` 直接重放 PublishedFrame 保留的片段与附属 DrawOps，直接使用 Painter 快照持有的已解码绘制内容。JUCE 平台事件进入 Arrange 后，先转换为 InputIntent，再由 Arrange 完成命中测试、语义处理、dirty 标记 与 FramePlan。

# 原则

JUCE 是舞台，不是导演。用户不需要接触内部 scene host、VBlankSource adapter 或 pipeline 细节。JUCE `paint()` 只读取 PublishedFrame 并绘制，不执行状态迁移、布局或 DrawOps 构建。

# 片段发布与重放

正式场景以 `PlacedPaintFragment` 发布：不可变 `PaintFragment` 保存本层命令、共享内容及子片段引用，位置保存在引用边。每个 Modifier 层构成完整的 before/content/after 状态作用域；节点内容与 Modifier 命令使用各自局部坐标。滚动、放置和 graphics transform 更新引用或相应层，稳定内容命令无需逐条改写。文字资源契约见 [文本输入与绘制](18-文本输入与绘制.md)。

自定义绘制在同一候选的布局、放置完成后，构建绘制片段前准备。QuickJS 用该层当前尺寸执行受控同步回调，回调把命令写成一条数值流（操作码与数值参数依次排列，非数值参数进引用表），原生 reader 一次取得整块缓冲并顺序解码；PaintFragment 保留不可变命令和共享后续内容。内容标记可出现零次或多次，重放在标记位置访问同一内容引用，保留当时的 clip/transform 状态。正式 paint 不跨入 JS，不获取下一帧状态；API 与实例缓存规则见 [Modifier 绘制](11-Modifier.md#绘制)。

`SceneFramePipeline` 不把片段树强制展平为完整 DrawOps 数组。诊断/测试的 `exportDrawOps` 与 `exportScene` 从同一片段模型遍历导出，导出副本不参与正式重放。后端只读取 PublishedFrame，不到可变 LayoutTree 补几何。聚焦 Input 的局部正文、选区、下划线和光标在同一片段流的 TextField 叶项原位替换；其兄弟排序、祖先几何和用户前景均按既有片段顺序处理。诊断页、badge、toast 仍独立叠加。

Modifier 的透明度沿作用域相乘，按既有逐操作透明度语义提交；这不等于离屏整层合成。可见性优化不得改变半透明叠加结果。阴影与模糊层是例外，它们按[位图缓存层](#位图缓存层)离屏合成；展平导出不含这些效果，只作诊断。候选资源、片段和命中快照遵守 [统一发布与失败边界](26-调度线程与帧阶段.md)。

# 保守可见性剔除

每个绘制操作提供保守绘制边界：文本使用真实字形边界与对齐，文本自裁剪/输入 viewport 按本身区域限定；线条与描边包含线宽和保守边缘。普通节点的布局矩形不能替代全部绘制影响。片段边界合并自身内容和子片段，按所在 Modifier 变换投影，坐标系明确属于片段入口。边界与片段一起不可变发布。

重放有两级剔除：先判断完整片段是否在有效裁剪区外，确定不可见时不访问内部 DrawOps；局部可见时逐操作判断。操作判断使用当时 JUCE clip/transform 状态，包括祖先、scroll viewport 和宿主 clip。浮点边界向外扩展并向外取整。状态操作始终成对执行；片段自成作用域，可整体跳过而不影响后继片段。

`overflow: visible`、溢出的子节点及外扩效果必须计入边界。未知边界向祖先传播为不可可靠剔除；无法可靠转换的极端坐标同样保留绘制。非矩形裁剪允许保守多画，不允许错误漏画。剔除只减少绘制，不冻结屏外状态、删除节点、退休事件或改变命中。

自定义绘制层的边界由命令求出：按重放顺序跟踪变换与裁剪栈，每条命令取变换后的外包盒并与当前裁剪相交，内容标记处的子片段按当时的变换并入。用户画到哪里边界就到哪里，不用布局 bounds 或准备回调的 size 限定；命令中含无法界定的操作时该层仍按未知边界处理。路径在解码时取全部端点、控制点与弧所在矩形的外包盒，描边再按线宽外扩（尖角线接按三倍线宽）；路径数据保持局部坐标，片段平移只移动其外包盒，重放按两者之差平移路径。文字在构建片段时经排版取墨迹边界。

效果层的边界：外阴影并入扩展、偏移与三倍标准差后的阴影范围；内容模糊把子片段边界外扩三倍标准差；内阴影与背景模糊不超出本层形状。

普通 scroll 仍进行必要测量、布局、协调与脏状态传播；约束和内容稳定时复用测量、文本和绘制片段。遮挡剔除与线程拆分属于独立能力，暂无能力。

# 位图缓存层

阴影、内容模糊、背景模糊、扫描渐变与需要栅格化的图片（像素缓冲、平铺与九宫格的矢量源、着色后的铺放源）由 JUCE 重放层按需建立离屏位图，不公开显式开关。位图在 JUCE 软件图像上生成，按当前物理缩放取像素尺寸，单边不超过 4096；模糊为三次可分离盒式模糊逼近高斯，图像外视为透明。

- 缓存键取不可变身份加参数摘要与像素尺寸：阴影取效果层，内容模糊取效果片段，渐变取渐变值，像素缓冲取提交生成的内容。片段替换即失效，身份对象由缓存持有，地址不会被复用。
- 背景模糊每次重放都要截取背景：从发布根重放到本层之前，按本层局部到根的逻辑变换的逆映射进离屏位图。键取截取像素的摘要，背景未变时跳过模糊。
- 含聚焦输入的内容模糊不进缓存，光标与选区不属于片段身份。
- 总字节预算默认 64 MB，按最近使用淘汰；单张超过预算的位图只用一次。命中、重建、淘汰、保留字节与条目数进入计数，由重放器的 `bitmapCache()` 读取。

GPU 离屏输出（着色器）将来接入同一层，见[远期想法暂存器](../proj/4：远期想法暂存器.md#gpu-效果与着色器)。

# 脏区重绘

重绘范围在 core 中随发布帧算出，写入 `FrameChangeSet.repaint`（`RepaintRegion`：整块标记或窗口坐标下的矩形列表）。JUCE 适配器只把它翻译为 `repaint()` 或逐块 `repaint(rect)`，不自行判断范围。

范围由新旧场景片段树并行比较得到：引用与偏移都相同的子树直接跳过；层与内容未变、只有子片段变化时向下递归；其余情况取该片段新旧边界的并集。边界按祖先偏移、Modifier 变换（取四角投影的外包盒）与裁剪换算到窗口坐标。层的前置命令中出现弹出命令、自定义绘制，或内容命令中带裁剪 / 变换时，不向下递归，直接取整片段新旧边界。聚焦 Input 的编辑命令变化时，范围取新旧 TextField 叶项区域；找不到叶项则整块。内容模糊层把子片段的变化扩散到模糊半径内，不向下递归，直接取整片段新旧边界。

背景模糊依赖绘制在它之前的内容：收集完比较结果后，凡任一变化区域与背景模糊层的采样范围（输出外扩三倍标准差）相交，就并入该层的输出范围；并入的范围可能再牵动其它背景模糊，反复到稳定。层无法给出单一作用域时整块重绘。

每块外扩 1 PX 兜住抗锯齿并向外取整、裁到视口；相交或间距不超过 8 PX 的矩形合并。以下情况整块重绘：首帧；显式整块回退（reload、HMR reload、root 重建等）；视口尺寸变化；错误屏进入或退出及诊断表层（错误屏、badge、toast）变化；路径上遇到未知边界或非有限坐标；收集时合并后仍超过 32 块；最终合并后超过 8 块或总面积超过视口一半。区域在收集时即与相邻区域合并，大量变化的代价不随区域数成倍放大。

局部重绘依赖上一节的保守剔除：宿主 clip 即脏区，重放跳过与之不相交的片段和操作。

诊断叠加层（帧时间、脏区闪烁等，见[开发期诊断表层](25-开发期诊断表层.md#帧诊断)）不在发布帧里：它画在场景之后，自身的重绘范围单独算出、单独请求，不并入 `FrameChangeSet.repaint`，也不进帧时间线，否则脏区闪烁会把自己的重绘也显示出来。宿主只在发布帧推进后转交场景脏区，叠加层变化不重复请求上一帧的场景脏区。

实际计数区分内容命令新建/复用、片段新建/复用、片段访问/跳过、DrawOp 访问/跳过、文字实际提交及被动 paint。准备、排版、glyph 提交与整体 paint 分别计时；绘制修饰器的准备（含 Canvas 重录）单独计时。逐帧的计数增量与耗时由帧时间线记录，见[帧诊断](25-开发期诊断表层.md#帧诊断)。同一重放实现可关闭剔除进行图像对照，不能维护另一套旧 renderer 作为对照。
