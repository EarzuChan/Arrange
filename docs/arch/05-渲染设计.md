# 宿主模型

JUCE 侧主入口是 `ArrangeEditor`。它托管 Arrange scene host，由 Arrange 内部完成输入归一、状态变更、布局、绘制准备与事件处理。

# JUCE 知道什么

- Editor / 画布尺寸。
- 绘制回调。
- 鼠标与键盘事件。
- 来自 FramePlan / PublishedFrame 的被动重绘请求。

# JUCE 不知道什么

- SFC、逻辑组件。
- 模板结构。
- 响应式状态。

# 职责

`arrange_core::DrawOpsBuilder` 只把 layout tree / scene state 收敛为平台无关 DrawOps。`arrange_juce::JuceDrawOpsPainter` 只把 PublishedFrame 中的 DrawOps 翻译为 JUCE 绘图调用，并通过 `ImageResourceCache` 读取包内图片资源。JUCE 平台事件进入 Arrange 后，先转换为 InputIntent，再由 Arrange 完成命中测试、语义处理、dirty attribution 与 FramePlan。

# 原则

JUCE 是舞台，不是导演。用户不需要接触内部 scene host、VBlankSource adapter 或 pipeline 细节。JUCE `paint()` 只读取 PublishedFrame 并绘制，不执行状态迁移、布局或 DrawOps 构建。
