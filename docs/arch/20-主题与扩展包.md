# 主题与扩展包

Arrange 核心不绑定设计系统。内建 FA 的无样式契约统一见 [内建 Arrangable](12-内建Arrangable.md)，核心不提供带主题皮肤的 Button、Card、Surface 或旋钮。

主题由用户或可选扩展包通过 provide/inject 显式管理。业务 Arrangable 读取自己的主题对象，再通过明确声明的参数及 Modifier 交付颜色、字体、间距与形状。内建 FA 不读取主题，不按上下文补色或皮肤。

```ts
provide(ThemeKey, theme)

const theme = inject(ThemeKey)
```

provide/inject 是同型上下文能力的唯一公开模型，不建立平行的 LocalContentColor、LocalTextStyle 或 Arrange Local 样式协议。密度、语言、快捷键和编辑器设置等行为服务也应采用明确的 typed key，其消费者和生命周期需要可追踪。

未来的设计系统、音频 Arrangable 和主题 token 包可以约定自己的对象结构，但不能成为核心依赖，也不能使未显式采用它们的 Text/Input/Icon 改变呈现。主题对象不放进隐式全局单例。
