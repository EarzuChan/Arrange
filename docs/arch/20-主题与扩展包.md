# 核心原则

Arrange 核心不绑定任何设计系统。

- 不绑定 Material 等设计系统。
- 内建组件保持无风格化或最低可用默认样式。
- 未来我们会推出官方设计系统和扩展组件包（以及官方 Theming 最佳实践），但不是现在，也不是强制要求使用。

# 上下文机制

主题与 token 沿用 Vue `provide/inject`，不重新发明 CompositionLocal。

适合通过上下文传递：

- colors
- typography
- spacing
- shapes
- density
- locale
- shortcut map
- editor settings

# 基础默认

核心只给最低可用默认：

- `Text` 默认 14sp 黑字。
- `Input` 默认基础光标、选区与文本样式。
- `Box`、`Row`、`Column`、`Spacer`、`Canvas` 默认无视觉风格。
- `Image`、`Icon` 不强加设计语言。

# 用户主题

用户可自行封装：

```ts
provide(ArrangeThemeKey, myTheme)
```

并在自己的组件中：

```ts
const theme = inject(ArrangeThemeKey)
```

核心只保证这些写法不与 Arrange 渲染系统冲突。

# 官方扩展包

未来可提供：

- 官方设计系统包。
- 官方音频组件包。
- 官方主题 token 包。

这些包不能成为核心依赖。

# 不做

- 核心不提供 Button/Card/Surface 等风格化组件。
- 核心不规定链接、警告、主色、面板、旋钮等样式。
- 核心不把主题对象塞进全局单例。
