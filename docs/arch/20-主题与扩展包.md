# 核心原则

Arrange 核心不绑定任何设计系统。

- 不绑定 Material 等设计系统。
- 内建组件保持无风格化或最低可用默认样式。
- 官方设计系统和扩展组件包属于可选上层包，不改变核心主题机制。

# 上下文机制

主题与 token 使用 Arrange Vue `provide/inject` authoring 语义，不重新发明第二套上下文系统。Arrange 提供 typed key 与 helper，并允许 compiler / runtime 将相关读取纳入 phase-aware dependency。

适合通过上下文传递：

- colors
- typography
- spacing
- shapes
- density
- locale
- shortcut map
- editor settings

# Arrange Locals

Arrange Local 是核心约定的 typed provide / inject。它用于表达 Compose CompositionLocal 同类能力，并服从 Arrange Vue 的 phase-aware reactivity。

建议 API 形态：

```ts
provideArrangeLocal(LocalContentColor, Color(0xFFE8EAED))
const color = useArrangeLocal(LocalContentColor)

provideContentColor(Color(0xFFE8EAED))
const color = useContentColor()
```

内置 Local：

- `LocalContentColor`：当前内容颜色。`Icon` 默认读取它；`Text` 在没有显式颜色与 `LocalTextStyle.color` 时读取它。
- `LocalTextStyle`：当前文本样式。`Text`、`Input` 可读取它作为默认文本样式。
- `LocalDensity`：密度与单位换算上下文。
- `LocalLayoutDirection`：LTR / RTL 布局方向。

可后续评估的 Local：

- `LocalContentAlpha`。
- `LocalDisabledAlpha`。
- shortcut map。
- locale。

默认优先级：

```txt
显式 prop
-> Modifier / component 参数
-> Arrange Local
-> 组件默认值
```

示例：

- `Icon` 未传 `tint` 时读取 `LocalContentColor`。
- `Text` 未传颜色时先读 `LocalTextStyle.color`，再读 `LocalContentColor`。
- 未来组件库的 `Button` / `Surface` 可在子树 provide 新的 `LocalContentColor`。

核心只约定 Local 的读取语义，不强制用户采用某个主题对象结构。

# 基础默认

核心只给最低可用默认：

- `Text` 默认 14sp 黑字。
- `Input` 默认基础光标、选区与文本样式。
- `Box`、`Row`、`Column`、`Spacer`、`Canvas` 默认无视觉风格。
- `Image`、`Icon` 不强加设计语言。

# 用户主题

用户可自行封装：

```ts
provide(ArrangeThemeKey, myTheme)
```

并在自己的组件中：

```ts
const theme = inject(ArrangeThemeKey)
```

核心只保证这些写法不与 Arrange 渲染系统冲突。

# 官方扩展包

未来可提供：

- 官方设计系统包。
- 官方音频组件包。
- 官方主题 token 包。

这些包不能成为核心依赖。

# 不做

- 核心不提供 Button/Card/Surface 等风格化组件。
- 核心不规定链接、警告、主色、面板、旋钮等样式。
- 核心不把主题对象塞进全局单例。
