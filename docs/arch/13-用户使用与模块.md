# 用户拿到什么

# JS / Node 侧

用户安装：

```bash
pnpm add @arrange/runtime
pnpm add -D @arrange/vite-plugin
```

可选脚手架：

```bash
pnpm create arrange
```

用户从 `@arrange/runtime` 获得：

```ts
import {
  createApp,
  Box,
  Row,
  Column,
  Text,
  Input,
  Image,
  Canvas,
  m,
  dp,
  sp,
  Color,
  Alignment,
  Arrangement,
  useParameter,
  useHost,
} from "@arrange/runtime"
```

# C++ / JUCE 侧

用户引入 Arrange C++ 库或 JUCE module，并通过 `ArrangeEditor` 返回插件 Editor。C++ 入口、`EditorConfig`、`useLive`、`useDist` 与 Debug / Release 加载规则见 [App入口](02-App入口.md)。

# Authoring 流程

1. 在 Node/Vite 源码项目里写 Arrange App。
2. `pnpm dev` 启动 Vite 开发服务器。
3. C++ 插件启动后自动连接 dev server。
4. `pnpm build` 生成发布产物。
5. 将构建产物目录放为运行时 `ui/` 目录。

# 涉及模块

- `@arrange/runtime`：用户写 UI 所需的一切运行时 API。
- `@arrange/vite-plugin`：开发、构建、HMR、诊断。
- `arrange_core`：布局、树、Modifier、命中测试。
- `arrange_quickjs`：JS 宿主与模块加载。
- `arrange_juce`：Editor、绘制、输入、错误屏。
- `arrange_audio/interop`：参数、host、C++/JS 互操作。
