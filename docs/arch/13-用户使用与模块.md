# 用户拿到什么

# JS / Node 侧

用户安装：

```bash
pnpm add @arrange/framework
```

可选脚手架：

```bash
pnpm create arrange
```

用户从 `@arrange/framework` 获得：

```ts
import {
  createApp,
  Box,
  Row,
  Column,
  Text,
  Input,
  Image,
  Canvas,
  m,
  dp,
  sp,
  Color,
  Alignment,
  Arrangement,
  useParameter,
  useHost,
} from "@arrange/framework"
```

# C++ / JUCE 侧

原生侧通过 FetchContent 引入 Arrange 源码包并链接公开 target：

```cmake
target_link_libraries(MyPlugin PRIVATE Arrange::framework)
```

C++ 入口、`EditorConfig`、`useLive`、`useDist` 与 Debug / Release 加载规则见 [App入口](02-App入口.md)，native 外部消费约定见 [Native包消费与FetchContent契约](30-Native包消费与FetchContent契约.md)。

# Authoring 流程

1. 在 Node/Vite 源码项目里写 Arrange App。
2. `arrange dev` 启动开发服务器。
3. C++ 插件启动后自动连接 dev server。
4. `arrange build` 生成发布产物。
5. 将构建产物目录放为运行时 `ui/` 目录。
6. 原生用户工程通过 FetchContent 拉取 Arrange，链接 `Arrange::framework`。

# 涉及模块

用户侧只消费：

- `@arrange/framework`。
- `Arrange::framework`。

内部模块边界见 [模块边界](03-模块边界.md)。
