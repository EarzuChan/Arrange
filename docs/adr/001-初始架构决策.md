# 决策

## 使用 QuickJS

使用 QuickJS 作为嵌入式 JS 运行时。理由：小巧、可控、易嵌入，适合插件 UI 环境。

## 使用 Vue 自定义渲染器

复用 Vue SFC、模板、响应式与 HMR 生态，但渲染目标是 Arrange 界面树，不是 DOM。

## 使用 ArrangeEditor 作为公开入口

C++ 主写法是返回 `ArrangeEditor`，由 Arrange 托管整个 `AudioProcessorEditor` UI。低层根视图不是主入口。

## 使用代码声明 App source

用户通过 `EditorConfig::app.useDist(...)` / `useLive(...)` 声明 UI 包来源。`useDist(...)` 的相对路径仍按调用处源文件解析，不依赖 DAW 当前工作目录；旧的 `fromHere` / `fromPath` / `defaultApp` 已由 ADR 002 移除。

## 使用约定开发服务器

Debug 下优先读取 `ARRANGE_DEV_SERVER`；未设置时连接 `http://127.0.0.1:9178`。

## 使用 Vite 真 HMR

开发期热更新基于 Vite WebSocket/HMR 通道，不以轮询 bundle 文件作为主设计。

## 使用错误屏兜底

加载、运行、热更新或协议错误最终进入 Arrange 错误屏，并允许用户手动重试。

## 使用 Compose Foundation 风格语义

布局、样式、交互以 Compose Foundation 为蓝本；明确不采纳 Web/CSS/HTML 模型。

## 使用 JUCE 逻辑坐标作为 dp

`dp` 直接映射 JUCE 逻辑坐标，不额外做系统 DPI 缩放。`px` 仅服务 Canvas、位图或高级缓存。

## 颜色 API 对齐 Compose

颜色主写法为 `Color(0xAARRGGBB)`。JUCE 只是绘制后端，不决定用户 API。

## 支持固有尺寸测量

布局系统支持 `IntrinsicSize.Min/Max` 与四类固有尺寸查询。

## 使用 Modifier 作为样式与通用交互入口

`class`、`style`、SFC `<style>` 不参与渲染；通用点击走 `m.clickable` 等 Modifier，不走 Vue `@click` 主模型。

## Canvas 是一等绘制节点

`Canvas` 是内建节点，用于波形、频谱、EQ、压缩曲线、音符块等音频 UI。具体绘制 API 单独设计。

## Lazy 集合使用数据加 slot

Lazy 组件使用 `items` 加 `#item` slot，避免 Vue `v-for` 预创建大量节点。

## 区分 UI 源码项目与 UI 构建产物目录

用户可显式指定 UI 产物包目录；不指定时默认按约定加载 `ui/`。一个目录/包就是一个 UI 产物包，多入口不需要多 manifest。

## 使用 UI 产物包默认目录

不填路径时，Arrange 默认按约定加载 `ui/`。显式路径优先；同一包可暴露多个入口，但无需额外 manifest。

## 拆分 JS 包与 C++ 模块

JS 侧以 `@arrange/runtime` 和 `@arrange/vite-plugin` 为主；C++ 侧拆为 core、quickjs、juce、interop/audio 等边界。

## Bridge 传树操作批次

Vue 自定义渲染器负责 diff，Bridge 传递 create/patch/insert/remove 等批量操作，C++ core 维护真实界面树。

## Bridge 生产协议不用 JSON

生产路径使用简明 command buffer / handle / opcode。JSON 只作为调试镜像、trace、错误诊断与测试快照，不作为 JS 到 C++ 的主通信协议。

## Vue 更新按变化提交

Vue renderer 只在响应式变化后提交差异批次，不按 tick/frame 同步整棵界面树。

## 布局测量与绘制在 C++ 侧执行

JS 描述 UI 意图；C++/JUCE 负责布局、文本测量、资源 intrinsic size、命中测试与绘制。

## 事件分离散与连续

离散事件立即派发；连续事件默认合并到 frame / 调度点。没有监听兴趣的节点不跨界派发事件。pointer capture、focus 与无障碍语义单独建模。

## 高频数据不走 Vue 大对象 diff

Canvas、动画、频谱、波形、meter 等高频路径使用专门通道、快照或缓存，不让 Vue 每帧 diff 大数组。

## 参数 gesture 由组件或 helper 管理

参数读取不产生 gesture；一次性设置自动 complete gesture；连续编辑由参数绑定组件或 gesture helper 自动 begin/set/end。
